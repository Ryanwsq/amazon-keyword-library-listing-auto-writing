## 1. 运行原则

- 用户只在开头提交产品名称、五点/细节、结构化事实、直接竞品、目标Amazon类目，以及该类目是否存在多个稳定产品类型细分；用户不指定一级品类核心大词或产品细分核心词。主任务一次锁定Run后调度到最终输出。
- 正式只读验证期间，知识、Skills、合同和流程保持只读。发现的错误只进入本轮同一个问题文档；整轮结束后再逐项确认和修改。
- 副任务只回传最小业务工作簿、manifest和紧凑状态，不把逐页接口正文或逐行大表贴进主任务对话。
- 每个执行模块必须由对应长期副任务完成并正式回传；主任务不得因副任务不可用、未初始化、操作不便或已能看到证据而代跑。只有用户了解影响后明确批准的一次性Run例外可以接收已经产生的证据，且必须保持可见。
- Amazon联想是必选来源；未执行时可以保留问题证据，但正常案例不得标记完成。
- 缺字段不删词，未执行不写成零结果，范围外不写成数据缺失，planned能力不冒充已验证。

## 2. 输入锁定

主任务锁定：`Run_ID`、仓库revision、站点、产品事实、自有品牌、SKU事实、直接竞品、用户确认的目标Amazon类目及是否存在多个稳定产品类型细分、来源周期、规则版本和本机运行目录。事实中的单位先完成确认；任务ID、绝对路径和授权只写入Git忽略的本机映射。

主任务不让用户命名核心词，也不在SIF回传前凭标题长词直接锁定。主任务结合锁定产品事实卡、直接竞品同对象身份和SIF真实流量候选，独立确认唯一一级品类核心大词。只有用户确认目标类目存在多个稳定产品类型细分时，主任务才可用同一证据发现、验证最多一个产品细分核心词；用户确认不存在时该字段必须留空。单独卖点、配置、配件、材质、尺寸、功能、容量、使用场景或高流量长词不能创建细分核心层级。存在细分核心词时主执行锚点等于该词，否则等于一级品类核心大词。强等价表达必须与主执行锚点双向替换后中心商品不变；上位品类、宽泛用途和相邻细分流量词单独记录，不获得核心或等价保护。流量只在同一语义层级内排序。

## 3. 第一板块：三来源采集与机械合并

### 3.1 SIF竞品反查

对获准竞品按当前接口合同采集完整响应并本地保存。业务回传只保留七列：`竞品ASIN、SIF返回序号、英文关键词、ABA排名、搜索量、Top3点击份额、Top3转化份额`，另给紧凑核心词候选摘要。

首选SIF MCP；MCP不可用时允许切换到同一SIF提供商的已登录网页入口。ASIN、站点、查询语义、七个业务字段和完整性门保持一致，并记录提供商、入口、查询时间与原始导出/可见证据。只有稳定来源事件标识、可去重且可证明无遗漏/无重复时才可断点续采；否则从受影响ASIN的完整查询重新开始。

SIF副任务正式回传后，主任务结合用户的类目细分回答、产品事实和直接竞品身份锁定唯一一级品类核心大词，并仅在回答为“存在多个稳定产品类型细分”时判断可选细分核心词，再锁定主执行锚点、强等价表达及宽泛/相邻流量词。SIF流量单独存在只产生候选；高覆盖、高返回位置、高ABA或高搜索量不能把卖点、配置、用途、上位品类或相邻细分词提升为细分核心词或强等价表达。

### 3.2 并行采集

锚点和种子确认后并行：

- Amazon联想：输入固定为唯一一级品类核心大词，不使用可能等于细分核心词的主执行锚点；保持Amazon US未登录、类目All、邮编10001。首选Codex内置浏览器，当前设备无法稳定识别或操作时使用普通Chrome备用，执行同一固定输入矩阵。只采集搜索框上方关键词联想区中的普通关键词建议行、关键词建议卡片和关键词建议组内选项；关键词建议被该区域内轮播或横向控件遮挡时保持输入不变并使其完整可见，保存操作前后证据，仍不完整可见时只记异常。底部商品卡、价格卡和商品轮播全部排除，即使可见也不形成来源事件。
- 卖家精灵扩词：每Run只锁定一个代表种子；存在细分核心词时使用该词，否则使用一级品类核心大词。强等价表达和宽泛/相邻流量词不默认成为种子。首选卖家精灵长期副任务内置浏览器中的已登录网页端；页面存在完整官方导出时必须优先使用，每次完整导出为一个版本化Pass。保存导出任务身份、时间、页面声明总数和原始文件，并以实际行数、唯一机械键和四个业务字段闭合。网页不可用时才切同提供商MCP；只有官方导出不可用且逐页仍可证明完整性时才允许逐页备用。账号、密码和会话只属于设备本地，不进入Git或交付物。

### 3.3 主任务机械合并

三来源拥有副任务都正式回传后，主任务只按NFKC、英文小写、去首尾和压缩空格生成机械键。不得纠错、词干化、同义合并、品牌删除、语义过滤或流量删词。没有正式回传时报告受影响模块并等待；一次性用户例外不改变默认所有权。

规范ABA/月搜索量优先卖家精灵，词不在卖家精灵时才回退SIF；Top3只取SIF。SIF/联想独有词的中文翻译在合并后一次性补充。

第一板块工作簿固定：

1. `Sheet1_关键词池`：`Keyword_ID、英文关键词、中文翻译、ABA月排名、月搜索量、流量数据来源、关键词来源、Top3点击份额、Top3转化份额、数据状态`。
2. `Sheet2_任务信息与类目锚点`：任务/来源摘要、SKU事实卡、类目锚点卡和核心大词候选；锚点卡分别记录一级品类核心大词、可选细分核心词、主执行锚点、强等价表达、宽泛/相邻流量词、单一卖家精灵种子、确认依据、通用词库资格边界和完整词覆盖边界。

## 4. 第二板块：品类相关性清洗

第二板块不新增词，不复制完整源表，不打第三板块语义标签。先执行ABA<=1,000,000或月搜索量>100的OR门。通过后，机械键与本Run一级品类核心大词、可选细分核心词或强等价表达完全一致的词直接进入Sheet2，但必须保留层级。其余词按完整短语中心购买对象判定唯一去向。可靠单复数/所有格/空格/符号噪声/短编辑变体加普通属性、结构、材质、尺寸、功能、价格、配送、风格、人群、场景或随本体配置时仍可为Sheet2；不可靠字符串不靠来源、流量或共享词根放行。决定性修饰语、商品头部或配件语法可以改变中心商品。一级品类归属仍无法确认的词进入Sheet3并标记歧义人工复核；只有中心购买对象已确认属于一级品类、但与目标细分的关系仍不明时，才保留在Sheet2并进入资格待复核。`本体 for 场景`与已形成其他商品类别的`场景+核心词`按实际交付物分别判断。配置连接词只提供语法信号；并列连接可能表达两个主要商品，不能自动当作配置。其他语言按本语言商品头部、修饰关系和词序判断。

三去向完成后，每个Sheet2行再写`通用词库资格=纳入/不纳入/待复核`。一级品类核心大词、细分核心词、强等价表达及目标细分同对象扩展词可纳入；同一级品类其他细分、宽泛用途/场景流量词或不能唯一描述目标对象的词不纳入；`待复核`只用于一级品类归属已确认但目标细分关系未解决的Sheet2行，未解决前不进入下游产品强相关人口。所有规则整批应用，并反向抽查Sheet2误放、Sheet3误摘与资格误纳。

工作簿固定四Sheet：

1. `Sheet1_事实与类目锚点`：SKU事实卡和类目锚点卡。
2. `Sheet2_品类相关`：十四列，含Top3快照、中心购买对象、品类关系、通用词库资格和保留理由。
3. `Sheet3_其他摘除`：十三列，含流量门、摘除主类型/理由和人工复核状态；不含Top3。
4. `Sheet4_二类词`：十二列，含直接替代关系；不含Top3，允许零行。

完成门：`Sheet2+Sheet3+Sheet4=第一板块输入人口`，每个`Keyword_ID`恰好一个去向，`纳入+不纳入+待复核=Sheet2人口`，原词和来源指标不改写，缺值不填0；另抽查一级品类核心大词、细分核心词、强等价表达、宽泛/相邻流量词、可靠变体加非变物属性、本体带配置、本体用于场景、并列多商品、其他语言商品头部、其他商品类别和独立配件边界，并反向抽查Sheet2误放、Sheet3误摘、资格误纳及人工复核假阴性，再完成四Sheet公式、渲染和目视复核。

## 5. 第三板块：并行分类与词频

清洗闭环后，分类与词频并行，共享锁定的第二板块版本但互不读取结果。

### 5.1 分类

分类过程工作簿只含增强后的Sheet2和Sheet4：

- Sheet2完整保留原十四列和上游通用词库资格，再追加`流量层、长尾主分组标签、LT分组、分类状态`和N个实际有值的品类自适应语义列。
- Sheet4在原十二列后只追加上述四个固定列，不加完整语义列。
- F1/F2/F3/F4/F5按ABA 1–10k/10–20k/20–50k/50–100k/>100k。
- 只有F5填写唯一主分组和LT；同组ABA升序，每20词一组。ABA缺失不伪造层或LT。

ABA排名未抓取到或不可用时，分类状态精确写`关键词ABA排名缺失`，流量层、主分组和LT留空，不以搜索量反推。月搜索量未抓取到或为空时写`搜索量缺失`；来源明确返回无搜索量或0时写`没有搜索量`。有效ABA仍按阈值分层。三种行级数据状态不提前停止整批；受影响主键、原值和状态写入manifest及唯一问题文档。最终装配保留这些状态，独立QA由主任务集中向用户确认；确认未闭合时可存在最终工作簿候选，但QA结论保持`incomplete`，不得标记完成。

否词库另输出五列`Keyword_ID、英文关键词、中文翻译、否词类别、收录理由`。它不包含否定方式；流量不足/缺失、歧义和待复核词不自动收录。

### 5.2 词频

只读取Sheet2中`通用词库资格=纳入`的英文关键词，输出一张Sheet中的两张并列表：

- `排名、单词、出现次数`
- `排名、相邻双词、出现次数`

固定英语介词白名单`EN_PREP_CORE_V1`的48个精确token从单词统计删除，并作为双词硬断点；不得跨介词连接。`a/an/the`、`and/or`、`up/down/off/out/as/like`明确保留，不做上下文词性重判或多词介词识别。版本、数量、内容或内容哈希不一致时停止。保留次数1，不增加搜索量、ABA、频段、权重或竞争字段。

## 6. 第三板块：并行竞争与趋势

分类完成后，竞争与趋势并行。

### 6.1 竞争

人口只含Sheet2中`通用词库资格=纳入`的F1–F4。优先复用第一板块Top3；任一缺失/冲突时才按完整词精确补拉SIF。固定十二列：`Keyword_ID、英文关键词、中文翻译、流量层、Top3点击份额、Top3转化份额、点击集中等级、转化集中等级、点击转化差、结构判断、综合竞争等级、数据状态`。

Top3阈值为30/50/70%；差值为转化减点击，±15个百分点区分结构。缺任一值、冲突未解、周期或单位不明时不出等级。不得加入其他竞争指标、样本门或广告建议。

### 6.2 趋势

人口只含Sheet2中`通用词库资格=纳入`的F1–F3，来源优先级固定为`SellerSprite -> Sorftime`。默认使用卖家精灵完整精确词月搜索量；卖家精灵不可用时，对本Run全部趋势人口切换到Sorftime。同一Run只允许一个锁定提供商，主来源中途失败时保留诊断证据并从头用备用来源重跑全部人口，不混源或跨源补值。每词至少拉取24个完整月份：

- 最近12月矩阵：每月`月搜索量、月环比、月同比`三行，共36行。
- 最近4完整季度矩阵：每季`季度搜索量、季度环比、季度同比`三行，共12行。
- 两张实际搜索量图：月图覆盖全部可用完整年月，季度图覆盖全部可用完整自然季度；每个关键词在每张图恰好一条线。环比和同比只留在矩阵表格。

缺失和0分母留空，不填0、不插值、不前值延续；不完整季度留空且不进入季度图。不得生成趋势标签、季节性或广告建议。

   2. `SKU事实卡`
   3. `品类产品通用词库`
   4. `二类词`
   5. `关键词竞争性分析`
   6. `关键词趋势性分析`
   7. `词频统计`

过程目录保留真实过程工作簿、manifests、原始响应、分页清单、计算、渲染、检查、唯一问题文档和质量报告；不放缓存、依赖、临时脚本、重复副本、凭据、任务ID或绝对路径。

### 7.1 最终总表

最终总表覆盖第一板块机械去重全人口，每个`Keyword_ID`一行，使用`最终去向`标记三去向。固定51列加N个动态语义列，新增并传递`通用词库资格`，其余覆盖身份/来源/逐行版本、清洗理由、分类、竞争摘要、趋势摘要、否词和后置广告状态。详细Top3及竞争结构是唯一明确排除的原字段组，只留独立竞争Sheet。广告资格和投放动作当前写`未评估/后置`。

### 7.2 品类产品通用词库

只从总表中同时满足`最终去向=品类相关`和`通用词库资格=纳入`的行机械筛选。每个流量层和每个动态语义分类使用三列块`关键词、月搜索量、竞争性强度`。上半区五个流量层块依次显示为`F1 核心大词、F2 二级词、F3 中流量词、F4 中长尾词、F5 长尾词`；这只改变表头，不改变内部F1–F5编码、ABA阈值、人口或下游范围。下半区按动态列顺序每行四个语义块。多标签词可以进入多个块，同块内去重；`不纳入/待复核`零混入，不显示ID、翻译、ABA、来源或理由。

### 7.3 二类词

最终`二类词`Sheet机械复制分类完成的`Sheet4_二类词`全人口，不从最终总表重新筛选或判断。固定十六列为第二板块十二列`Keyword_ID、英文关键词、中文翻译、ABA月排名、月搜索量、关键词来源、流量数据来源、数据状态、中心购买对象、二类商品类型、共同核心购买任务、直接替代理由`，加分类四列`流量层、长尾主分组标签、LT分组、分类状态`。每个二类词主键恰好一行；上游零行时只保留表头。不得加入Top3、动态语义列、竞争、趋势、通用词库资格、否词方式、广告资格或投放动作。

## 8. 独立质量验证
