# Standalone competition output contract

## Input lock

锁定分类工作簿名称/哈希、Sheet2总人口与通用词库资格人口、`通用词库资格=纳入`的F1–F4唯一Keyword_ID人口、第一板块Top3快照、站点、周期、补拉批次和竞争版本。`不纳入/待复核`、F5、Sheet3、Sheet4和SKU事实不输入。

## Fixed fields

固定十二列并按此顺序：`Keyword_ID、英文关键词、中文翻译、流量层、Top3点击份额、Top3转化份额、点击集中等级、转化集中等级、点击转化差、结构判断、综合竞争等级、数据状态`。

站点、分析周期、补拉批次、规则版本和原始响应相对目录写manifest，不逐行重复。

## Source and completeness

第一板块两项完整且无冲突则复用。任一缺失或冲突才按完整词补拉SIF；如只缺一项，也采用一次补查返回的同周期成对值，不混合周期。近似词、词根、历史均值、平均冲突值和其他来源不得替代。

Top3任一缺失、冲突未解决、周期不明、非完整词精确或单位不明时，派生列和综合等级留空，数据状态写`数据不足/人工复核`。SIF 0–1值在单位确认后转百分比。

## Calculation

单项集中等级：`<30%=低`、`30%–<50%=中`、`50%–<70%=高`、`>=70%=极高`。

`点击转化差=Top3转化份额-Top3点击份额`：

- >=15个百分点：`头部转化效率壁垒`
- <=-15个百分点：`点击流量被锁但购买相对分散`
- 其余：`结构基本一致`

综合矩阵（行=点击，列=转化；列顺序低/中/高/极高）：

| 点击层 | 低 | 中 | 高 | 极高 |
|---|---|---|---|---|
| 低 | 低 | 中 | 高 | 高 |
| 中 | 中 | 中 | 高 | 高 |
| 高 | 高 | 高 | 高 | 极高 |
| 极高 | 高 | 高 | 极高 | 极高 |

跨层分化由`结构判断`表达；`综合竞争等级`只写低/中/高/极高。等级描述头部集中/锁定程度，不生成广告投放结论。

## Excluded

不建立Competition_Record_ID，不输出CPC、SPR、商品数、市场CVR、Top3 ASIN、竞争者列表、比较池、样本门、置信度、摘要或广告行动建议。

## Quality gate

1. 人口等于Sheet2中`通用词库资格=纳入`的F1–F4唯一主键数。
2. 每个主键一行且可回查；`不纳入/待复核`、F5、Sheet3和Sheet4零混入。
3. 正式输入只含同周期完整词Top3两项。
4. 单项层、差值、结构和综合矩阵可复算。
5. 不满足完整性门的行无派生等级。
6. 字段恰好十二列，公式扫描、渲染和目视复核通过。
