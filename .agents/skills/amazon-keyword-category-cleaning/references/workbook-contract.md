# Category-cleaning workbook contract

## Input lock

锁定第一板块工作簿名称、SHA-256、唯一关键词人口、Keyword_ID、类目锚点版本、用户确认的目标类目是否存在多个稳定产品类型细分、一级品类核心大词、可选细分核心词、主执行锚点、强等价表达、宽泛/相邻流量词机械键及各自确认依据、通用词库资格边界、完整词覆盖边界、SKU事实和清洗版本。第二板块不新增关键词，也不复制完整源表。

## Fixed workbook

### Sheet1_事实与类目锚点

- SKU事实卡：`事实分类、事实字段、确认值、状态/来源`。
- 类目锚点卡：`锚点字段、确认值、状态/依据`。
- 锚点至少覆盖版本、一级品类、是否存在多个稳定产品类型细分、一级品类核心大词、可选细分核心词、主执行锚点、强等价表达、宽泛/相邻流量词、Amazon联想锚点、卖家精灵种子集合、目标SKU细分品类、中心购买对象、Sheet2纳入边界、通用词库资格边界、配件/互补品边界、完整词覆盖边界、Sheet4直接替代边界和歧义事项。Amazon联想锚点固定为一级品类核心大词；存在细分核心词时，卖家精灵种子集合固定包含一级品类核心大词和细分核心词，否则仅包含一级品类核心大词。Sheet4边界必须记录是否允许同一级品类内的决定性稳定替代类型；存在细分核心词时主执行锚点必须等于该词，否则等于一级品类核心大词。

### Sheet2_品类相关

固定十四列：`Keyword_ID、英文关键词、中文翻译、ABA月排名、月搜索量、关键词来源、流量数据来源、Top3点击份额、Top3转化份额、数据状态、中心购买对象、品类关系、通用词库资格、保留理由`。

`品类关系`只用`一级品类核心、产品细分核心、强等价同对象、目标细分同对象扩展、同一级品类其他细分、宽泛/相邻流量、关系待复核`。`通用词库资格`只用`纳入、不纳入、待复核`：前四种关系在完整词无冲突时写`纳入`；其中`目标细分同对象扩展`依据完整词中心商品判定，不要求显式出现细分核心词或强等价表达，也不因目标SKU缺少某项属性、材质、结构、功能或配置而降级。第五和第六种关系中留在Sheet2的行写`不纳入`；只有中心购买对象已确认属于一级品类、但目标细分关系仍无法消歧时，才写`关系待复核/待复核`并在保留理由说明。一级品类归属不明的词不得进入Sheet2，必须进入Sheet3人工复核。该字段不改变Sheet2品类相关去向，但决定产品强相关下游人口。

第二板块不打语义标签。Top3缺失留空并在数据状态标记；后续竞争只对F1–F4缺失/冲突词补拉，不覆盖本表快照。

### Sheet3_其他摘除

固定十三列：`Keyword_ID、英文关键词、中文翻译、ABA月排名、月搜索量、关键词来源、流量数据来源、数据状态、流量门状态、中心购买对象、摘除主类型、摘除理由、人工复核状态`。

流量门状态只用`通过-ABA、通过-搜索量、通过-双项、未通过、缺流量数据`。摘除主类型至少覆盖流量门、第三方品牌/IP、Gift、配件/零件/耗材/服务、多商品、泛词/残缺/歧义、仅场景/人群/活动、非直接替代、完全无关和其他。无法确认中心购买对象是否属于一级品类的词使用`泛词/残缺/歧义`并标记人工复核；已确认一级品类归属、仅目标细分关系不明的词不得进入本Sheet。Sheet3不保留Top3，不输出否定方式。

### Sheet4_二类词

固定十二列：`Keyword_ID、英文关键词、中文翻译、ABA月排名、月搜索量、关键词来源、流量数据来源、数据状态、中心购买对象、二类商品类型、共同核心购买任务、直接替代理由`。

全部Sheet4行已经通过流量门；不重复流量门，不保留Top3，不进入竞争/趋势。允许只有表头。

每个Sheet4行必须是完整商品，与目标商品解决同一主要购买任务、无需额外主要商品并通常进入同次购买比较。用户确认一级类目存在多个稳定产品类型细分时，中心对象可以仍在一级品类内，但完整短语必须以决定性语义形成与目标不同且市场认知稳定的产品类型、受众定位或购买路径。普通属性、外观、结构、材质、尺寸、功能、配置或一般受众/场景修饰不能单独建立二类词；同类词不得整体自动转入Sheet4。

## Manifest

只记录运行身份、输入名称/哈希/人口、事实和锚点状态、输出名称/哈希、三去向行数、重复/缺失主键、缺流量、Top3缺失、来源冲突、人工复核、边界族抽查及三个非纳入去向的目标同对象假阴性抽查人口/结果、公式/渲染/目视检查、状态和唯一问题文档相对路径。

## Quality gate

1. `Sheet2+Sheet3+Sheet4=输入人口`。
2. 每个Keyword_ID恰好一个去向，三表不交叉。
3. 原词、主键和来源指标不改写；缺值不填0。
4. Sheet2除受控`品类关系`和`通用词库资格`外无第三板块语义标签/SKU精准匹配；Sheet3无Top3/否定方式；Sheet4无Top3/竞争/趋势。
5. 一级核心商品加普通属性、外观、结构、材质、尺寸、功能或配置时，不因SKU不具备而降级、摘除或转为二类词；SKU事实只用于中心对象和决定性稳定类型消歧，材质本身不能建立另一稳定产品类型。
6. 每个Sheet3行有明确主类型/理由；每个Sheet4行满足完整商品、同一主要任务、无需额外主要商品、通常同次比较四门。类目存在多个稳定产品类型细分时，Sheet4可包含决定性的同品类稳定替代类型；普通同类词不得批量转入。
7. 四Sheet公式扫描、渲染和目视复核通过。
8. 通过流量门的精确一级品类核心大词、细分核心词和强等价表达全部在Sheet2且层级正确；核心词根不能把中心商品已由完整短语改变的词带入Sheet2。
9. 每个Sheet2行的`通用词库资格`都有可追溯的中心商品和品类关系依据；`纳入+不纳入+待复核=Sheet2人口`，待复核零混入产品强相关下游人口。目标同对象的普通非变物扩展不以显式出现细分核心词/强等价表达或SKU配置一致为纳入硬门。Sheet2待复核人口全部已确认一级品类归属，Sheet3歧义人工复核人口全部尚未确认一级品类归属，两者零混用。
10. 已完成精确一级品类核心大词、精确细分核心词、精确强等价表达、可靠变体加非变物属性、宽泛/相邻流量词、本体带配置、本体用于场景、决定性稳定替代类型、并列多商品、其他语言商品头部、其他商品类别和独立配件边界抽查，并在manifest记录计数、结果及人工复核数。
11. 规则已对锁定人口整批执行；反向抽查同时覆盖Sheet2误放、通用词库资格误纳，以及`通用词库资格=不纳入`、Sheet3、Sheet4中的目标同对象假阴性。假阴性抽查必须覆盖一级核心商品加普通属性、材质、结构、功能和配置；人工复核样本中不存在只因常规属性/价格/尺寸/风格/配送修饰或可可靠识别的单复数、所有格、空格、符号噪声、短编辑/相邻换位变体而送审的假阴性；配置/并列连接及其他语言词序未被单一词面规则机械判定。
