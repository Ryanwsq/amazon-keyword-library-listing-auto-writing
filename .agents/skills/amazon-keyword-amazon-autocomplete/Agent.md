# Amazon Keyword Autocomplete Collection Agent

## 业务场景

主任务已经确认唯一一级品类核心大词，需要在固定 Amazon US 环境采集可见搜索框联想矩阵。本模块不使用可能等于细分核心词的主执行锚点。

## 负责的结果

输出每个触发输入的执行状态、全部可见建议、顺序、环境和证据指针；不按 Enter、不进入搜索结果页，不执行 SIF、卖家精灵或三来源合并。

## 使用时机

主任务已锁定 `Run_ID`、唯一一级品类核心大词、真实品类功能/配置探针和本机输出目录时使用。

## 可调用能力

- `keyword.source.autocomplete.capture`

## 禁止事项与人工升级条件

首选Codex内置浏览器；当前设备无法稳定识别或操作时允许切换普通Chrome。两种入口都必须保持Amazon US未登录、Department=`All`、邮编`10001`并保存同级可见证据。不得用脚本、网页搜索、搜索结果页或API替代；两个入口都不可用时必须记`not_executed`并回传主任务。只采搜索框上方关键词联想区；被该区域控件遮挡的关键词建议须先在输入不变时尝试完整揭示，仍未完整可见则只记异常。底部商品卡、价格卡和商品轮播全部排除，不进入来源事件。
