# Keyword classification output contract

## Input lock

锁定第二板块工作簿名称/哈希、Sheet2/3/4唯一主键人口、Sheet2品类关系/通用词库资格、站点、周期和分类版本。保留第二板块原表；SKU事实卡和词频值不输入。

## Classification workbook

只含两Sheet。

### Sheet2_品类相关

完整保留第二板块十四列，并按顺序追加：

1. `流量层`
2. `长尾主分组标签`
3. `LT分组`
4. `分类状态`
5. N个动态语义列

动态列根据当前一级品类、完整Sheet2人口和关键词文字生成。只输出至少一行有值的列；列顺序和含义写入manifest的`semantic_columns`。同列多值用`｜`，不另建多标签汇总列，不输出SKU事实匹配。`品类关系`和`通用词库资格`只从上游逐值复制，不由分类重算。

### Sheet4_二类词

完整保留第二板块十二列，只追加`流量层、长尾主分组标签、LT分组、分类状态`。不生成N个动态语义列。

## Traffic and LT

- F1：ABA 1–10,000
- F2：10,001–20,000
- F3：20,001–50,000
- F4：50,001–100,000
- F5：>100,000

ABA排名未抓取到或不可用时，`分类状态=关键词ABA排名缺失`，不推断流量层，主分组和LT留空。月搜索量未抓取到或为空时记`搜索量缺失`；来源明确返回无搜索量或数值为0时记`没有搜索量`。搜索量状态不覆盖有效ABA分层。

只有F5填写主分组和LT；主分组为`动态列名:标签值`，每词唯一。组内ABA升序，每20词拆一个LT组。

## Negative library

固定五列：`Keyword_ID、英文关键词、中文翻译、否词类别、收录理由`。

只收录Sheet3中语义明确且人工复核完成的原始完整词。仅流量失败/缺失、语义歧义或仍需复核的词不收录。不生成短语，不输出精准/词组否定、误伤列、广告层级、发布状态、ABA、搜索量或来源。

## Manifest

记录输入/输出哈希、Sheet2/3/4人口、F1–F5数量、`关键词ABA排名缺失、搜索量缺失、没有搜索量`各自的数量/受影响主键/原始值、动态语义列名/顺序/含义、F5主分组和LT数量、否词收录/排除计数、重复/空主键、公式、渲染和状态。这三种行级数据状态继续传递到compact/full QA允许缺口清单，不作为本阶段整批停止门，也不触发运行途中人工确认。

## Quality gate

1. 分类Sheet2/Sheet4人口分别等于上游且主键唯一；Sheet2品类关系和通用词库资格与上游同名、同序、同值。
2. F1–F5可由ABA机械复算；`关键词ABA排名缺失`行无伪造层/主分组/LT，`搜索量缺失/没有搜索量`行不填造搜索量且不影响有效ABA分层。
3. 动态语义列名、顺序和值与manifest一致，列非全空。
4. F5每词一次、恰有一个主分组，每LT<=20。
5. Sheet2无SKU/广告；Sheet4无完整动态语义/竞争/趋势。
6. 否词库只含符合收录条件行且恰好五列。
7. 所有输出公式扫描、渲染和目视复核通过。
8. 三种数据状态的计数、主键、原始值与工作簿一致，并已写入最终QA允许缺口清单；受影响派生字段未伪造。

## Runtime calculation

F1–F5和三种行级数据状态使用仓库级`classify-traffic`确定性计算并锁定执行器版本、输入/输出人口及结果哈希。动态语义列、F5唯一主标签、LT和否词语义仍由本合同执行，确定性核心不得生成或猜测这些字段。工作簿写入、列顺序、公式、渲染和目视门保持不变。
