# SellerSprite expansion source contract

## Input lock

- `Run_ID`、站点、查询月份、一个主任务确认的代表种子、种子层级/依据、查询过滤条件、网页完整导出/逐页备用参数和本机忽略目录必须锁定。
- 存在已确认产品细分核心词时，代表种子必须为该词；不存在时，代表种子必须为一级品类核心大词。代表种子从第1页开始；本 Skill 不增加、替换、追加或语义合并种子。
- 业务字段固定映射为`keyword,keywordCn,searchRank,searches`；MCP备用的`returnFields`固定为这四项，网页原始导出可保留提供商原字段，但业务工作簿不得增加字段。
- 首选本长期副任务内置浏览器中的已登录卖家精灵网页端及其完整官方导出；每Run验证会话可用，不读取或留存凭据。网页不可用时允许同一卖家精灵提供商MCP。入口切换必须保持相同站点、月份、种子、过滤条件和四字段口径。

## Raw export and page record

每个官方导出Pass至少保留：来源记录ID、批次、入口类型、代表种子、Pass、站点、查询月份、过滤条件、导出任务身份、触发/完成时间、页面声明总数、原始文件路径/哈希、实际行数和唯一机械键数。解析事件另保留原始关键词、机械键、`keywordCn`、`searchRank`和`searches`。MCP响应或获准逐页备用还须保留页码、页内序号和分页包络。所有原始证据本地原样保存，不重算或补造字段；不记录账号、密码或会话内容。

## Pass and completeness gate

单一种子至少完成两个版本化Pass；第二Pass增加或交换机械键时最多追加第三Pass。首选每个Pass是一份完整官方导出，以实际返回行数和唯一机械键闭环，页面声明总数及其漂移只作证据。

只有官方导出不可用且完整性仍可证明时，才允许每个Pass从第1页连续到短页或空页；页边界重复原始行全部保留，机械键重复另行列示。入口间续跑必须锁定相同种子、月份、过滤条件、Pass身份和四字段，并用稳定事件账本证明无遗漏或重复；无法证明时新建版本并重启完整Pass。

## Four-column workbook

副任务按锁定顺序机械融合所有已取得事件，工作簿业务Sheet只能包含：`英文关键词`、`中文翻译`、`ABA月排名`、`月搜索量`。同一机械键多值冲突时展示首次非空原值，不平均、不覆盖原始证据；冲突组和全部来源指针写入清单。工作簿、清单都记录Run相对路径、哈希、事件数、唯一词数、Pass状态和损失风险。

## Handoff

回传主任务：四字段工作簿、Run相对路径、文件哈希、网页登录会话验证状态、入口类型、官方导出任务身份/时间、原始事件数、唯一词数、页面声明总数/实际行数轨迹、Pass收敛、重复/冲突/缺失、损失风险、完整性状态和异常摘要。不得回传凭据或会话内容。官方原始导出、逐页响应和原始行不进入主任务消息，只保留在 `.local/runs/<Run_ID>/keyword-sellersprite-collector/`。

## Stop

种子不是单一值、种子层级/依据缺失、细分核心词已存在却使用其他层级词时，不开始查询。网页登录与同提供商MCP均不可用、官方导出不可用且逐页完整性不能证明、入口身份无法对齐、报错、限流、结构异常、缺页、整页重复、循环、无继续进展或四字段结构性缺失时，停止受影响Pass并装配已取得结果。单行字段空白保留空值，不构成整批结构错误，但必须进入缺失清单；单一种子满足Pass门时才能写`complete_with_residual_risk`。
