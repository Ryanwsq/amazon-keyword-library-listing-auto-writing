# SellerSprite expansion source contract

## Input lock

- `Run_ID`、站点、查询月份、唯一一级品类核心大词、可选唯一产品细分核心词、两者层级/依据、锁定种子顺序、查询过滤条件、官网完整导出/MCP备用参数和本机忽略目录必须锁定。
- 存在已确认产品细分核心词时，种子按`一级品类核心大词、产品细分核心词`锁定为两个；不存在时只锁定一级品类核心大词。每个种子独立从Pass 1开始；本 Skill 不增加、替换、遗漏、追加或语义合并种子，强等价、宽泛、卖点、配置和场景表达不得成为额外种子。
- 业务字段固定映射为`keyword,keywordCn,searchRank,searches`；MCP备用的`returnFields`固定为这四项，网页原始导出可保留提供商原字段，但业务工作簿不得增加字段。
- 首选本长期副任务内置浏览器中的已登录卖家精灵官网及其完整官方导出；每Run验证会话与站点，不读取或留存凭据。只有官网完整导出链路不可用时才允许同一卖家精灵提供商MCP。入口切换必须保持相同站点、月份、种子、过滤条件和四字段口径。

## Raw export and page record

每个种子/官方导出Pass至少保留：来源记录ID、批次、入口类型、种子及层级、种子顺序、Pass、站点、查询月份、过滤条件、关键词挖掘页查询身份、当前顶部/左上导出入口证据、导出任务身份、导出记录状态、触发/完成时间、页面声明总数、本轮新完成原始文件路径/哈希、实际行数和唯一机械键数。导出入口按当前可见语义确认，不绑定固定selector、坐标或DOM路径；不得用页面抄取替代完整导出。解析事件另保留原始关键词、机械键、`keywordCn`、`searchRank`、`searches`及全部种子/Pass来源身份。MCP备用响应还须保留页码、页内序号和分页包络。每个种子/Pass的原始官方XLSX分别原样、版本化保存且不覆盖；不记录账号、密码或会话内容。

## Pass and completeness gate

每个锁定种子至少完成两个版本化Pass；仅以同一种子Pass 1与Pass 2的双向机械键差异判断，第二Pass增加或交换机械键时最多追加第三Pass。首选每个Pass是一份完整官方导出，以实际返回行数和唯一机械键闭环，页面声明总数及其漂移只作证据。全部种子分别满足本门后模块才完成。

只有官网完整导出链路不可用且MCP完整性仍可证明时，才允许受影响种子/Pass从第1页连续到短页或空页；页边界重复原始行全部保留，机械键重复另行列示。入口间续跑必须锁定相同种子、月份、过滤条件、Pass身份和四字段，并用稳定事件账本证明无遗漏或重复；无法证明时新建版本并重启受影响完整Pass。不得以手工逐页抄取网页结果作为入口。

## Four-column workbook

副任务按锁定种子顺序、Pass、页或导出行顺序机械融合所有已取得事件，工作簿业务Sheet只能包含：`英文关键词`、`中文翻译`、`ABA月排名`、`月搜索量`。同一机械键跨种子/Pass只保留一个业务行，多值冲突时展示首次非空原值，不平均、不覆盖原始证据；事件账本、冲突组和来源指针必须保留该词的全部种子/Pass身份。工作簿、清单都记录Run相对路径、哈希、事件数、唯一词数、逐种子Pass状态和损失风险。

## Handoff

回传主任务：四字段工作簿、Run相对路径、文件哈希、网页登录会话验证状态、入口类型、逐种子官方导出入口/任务/记录/完成文件证据、原始事件数、唯一词数、页面声明总数/实际行数轨迹、逐种子Pass收敛、重复/冲突/缺失、损失风险、完整性状态和异常摘要。不得回传凭据或会话内容。官方原始导出、MCP逐页响应和原始行不进入主任务消息，只保留在 `.local/runs/<Run_ID>/keyword-sellersprite-collector/`。

## Stop

一级核心缺失、细分核心状态不明、种子数量/顺序与层级锁不符、存在细分核心却遗漏一级或细分种子、出现任何额外种子时，不开始查询。官网完整导出链路与同提供商MCP均不可用、MCP分页完整性不能证明、入口身份无法对齐、报错、限流、结构异常、缺页、整页重复、循环、无继续进展或四字段结构性缺失时，停止受影响Pass并装配已取得结果。单行字段空白保留空值，不构成整批结构错误，但必须进入缺失清单；全部锁定种子分别满足Pass门时才能写`complete_with_residual_risk`。
