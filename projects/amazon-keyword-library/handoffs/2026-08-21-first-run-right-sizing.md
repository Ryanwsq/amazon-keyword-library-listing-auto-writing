## Confirmed changes

- SIF竞品反查仍按每个获准ASIN最近30天、接口上限300条执行。接口不支持选择返回字段，因此完整响应只保留在副任务本机忽略目录；副任务装配七列明细：竞品ASIN、SIF返回序号、英文关键词、ABA排名、搜索量、Top3点击份额、Top3转化份额，并另给核心词候选摘要。
- 卖家精灵关键词挖掘固定只请求`keyword,keywordCn,searchRank,searches`，即英文关键词、中文翻译、ABA月排名、月搜索量。每个种子至少两个收敛Pass，第二Pass仍增加或交换机械键时最多第三Pass。
- 卖家精灵副任务先把已取得事件机械融合为四列表，再只向主任务回传Run相对路径、文件哈希、原始事件数、唯一词数、Pass状态、字段缺失/冲突、分页状态和异常摘要；主任务以工作簿哈希加行号生成确定性回传行ID，逐页正文和内部事件ID不进入主任务消息。
- 竞争性只处理Sheet2 F1–F4，正式输入仅SIF Top3点击份额和Top3转化份额。先复用第一板块SIF明细，缺失或冲突词才按完整关键词、每批最多10词补查关键词历史。
- 竞争不再使用机会筛选、竞争格局、CPC、SPR、商品数量、市场CVR、入场信号、P33/P67、比较池或样本门。综合竞争等级直接等于两项Top3证据合成的头部锁定度。
- 趋势规则本轮未修改，等待后续单独调整。

## Context and completeness boundary

- 该设计缩减的是接口返回字段、业务工作簿字段和跨任务消息，不减少SIF的300条接口范围，也不按流量/相关性过滤卖家精灵关键词。
- 卖家精灵通过2–3个完整Pass观察键集合是否收敛；接口声明总数或页数漂移只作风险证据，稳定向前分页仍继续。
- SIF接口侧无法减字段，因此其节省主要来自不把完整响应复制进主任务上下文；完整原始证据仍可在锁定Run内回查。
