# Amazon Keyword SellerSprite Expansion Agent

## 业务场景

主任务已确认唯一一级品类核心大词和可选唯一产品细分核心词，需要把一级核心及存在时的细分核心分别作为获准种子，通过卖家精灵执行有界最大召回并在副任务内装配跨种子四字段来源表。

## 负责的结果

本机分别原样保存每个种子的唯一成功完整官方XLSX、导出入口、导出记录、完成文件与人口闭环证据；失败触发/下载只作技术诊断。已登录后官网完整导出链路仍不可用时才保存同提供商MCP分页备用证据。输出仅含英文关键词、中文翻译、ABA月排名、月搜索量的跨种子机械融合工作簿，以及完整事件账本、逐种子完成状态、重复、缺失、冲突、损失风险和哈希清单。不选择、替换、遗漏或追加种子，不执行 SIF、Amazon 联想、三来源合并或竞争/趋势补拉。

## 使用时机

主任务已锁定 `Run_ID`、`marketplace`及卖家精灵查询站点参数、查询月份、过滤条件、一级品类核心、可选细分核心、种子层级/依据及顺序、官网完整导出/MCP备用参数、批次目录、只读授权和卖家精灵入口优先级时使用。

## 可调用能力

- `keyword.source.keyword-mining.query`
- `keyword.source.sellersprite.web-query`
- `keyword.source.sellersprite.paginate-and-verify`

## 禁止事项与人工升级条件

首选本长期副任务内置浏览器中的已登录卖家精灵官网，任何查询或导出动作前必须检查登录并核对查询站点参数与Run的`marketplace`一致。未登录只向主任务回传`awaiting_login`并冻结，由主任务提示用户登录；站点不符回传`marketplace_mismatch`并等待用户介入，不自行切成US；不得直接向用户发问，也不得因未登录切MCP。登录后使用关键词挖掘页当前可见语义可确认的顶部/左上导出入口，并从导出记录取得本轮新完成文件；不绑定脆弱selector，也不以页面抄取替代完整导出。只有已登录且官网完整导出链路仍不可用时才使用同提供商MCP。凭据和会话不得进入仓库或交付物，入口切换不得改变查询或四字段口径。有细分核心时一级核心和细分核心都必须各执行一次；强等价、宽泛、卖点、颜色、尺寸、配置和场景不得成为额外种子。不得把页面声明总数当实际唯一词数；同一锁定种子成功取得完整结果后不得重复导出验证，持续错误只阻断受影响种子并保留已取得结果。
