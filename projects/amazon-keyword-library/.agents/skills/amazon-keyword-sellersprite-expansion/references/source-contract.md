# SellerSprite expansion source contract

## Input lock

- `Run_ID`、`marketplace`、卖家精灵查询站点参数、最近30天查询周期、唯一一级品类核心大词、可选唯一产品细分核心词、两者层级/依据、锁定种子顺序、查询过滤条件、官网完整导出/MCP主入口参数和本机忽略目录必须锁定。`marketplace`只允许`Amazon-US`或`Amazon-DE`；网页与MCP站点参数必须匹配，发现不一致时记录`marketplace_mismatch`、停止并通知用户介入，不得静默改成US。
- 存在已确认产品细分核心词时，种子按`一级品类核心大词、产品细分核心词`锁定为两个；不存在时只锁定一级品类核心大词。每个种子只取得一个成功完整结果；本 Skill 不增加、替换、遗漏、追加或语义合并种子，强等价、宽泛、卖点、配置和场景表达不得成为额外种子。
- 业务字段固定映射为`keyword,keywordCn,searchRank,searches`；MCP的`returnFields`固定为这四项，网页原始导出可保留提供商原字段，但业务工作簿不得增加字段。
- MCP首选，仅实际MCP明确报错时提示用户登录同提供商官网备用。完整读取`../../../../docs/mcp-first-source-access.md`；新Run使用v2 source_access及mcp-first-error-only-20260914。MCP正常不等待网页登录；零结果、缺字段、不完整响应不是MCP错误。入口切换保留同查询身份与四字段。
- 本阶段来源优先级只允许`卖家精灵MCP > 卖家精灵官网完整官方导出`。Sorftime官网只是账户/MCP配置入口，Sorftime网页和MCP均不得用于关键词挖掘或替代卖家精灵结果。

## Raw export and page record

### 最近30天与派发前锁

用户已确认此挖掘阶段使用提供商滚动“最近30天”，不推断最近完整日历月，也不因页面缺少该日历月改查更早月份。本规则不改变趋势模块的完整月口径。首次派发前即以`admission.query_lock`冻结当前Run/站点、一级与可选细分种子顺序、`query_period.kind=rolling-30-days`、页面周期标签和全部过滤条件；无附加过滤写空对象，不省略。来源返回起止日则原样记录；未返回写“来源未返回”，不得倒推或把滚动窗口改成月度。网页/MCP不能实现同周期时停止受影响来源，不静默换月。查询锁格式见`../../../../docs/dispatch-control-contract.md`。

### 一次已自动填充登录恢复

此前已认证的本任务跳回同一提供商登录页，且密码管理器已填满账号和密码框时，仅允许点击一次Login，然后重新验证提供商、账户身份、站点和查询锁。只确认非敏感填充状态，不读取、显示、复制、导出、记录、修改或补填凭据；无法安全确认时交用户。空白/部分填充、验证码/MFA、登录失败、错账户/站点和再次跳转仍回传`awaiting_login`。`../../../../scripts/source_execution.py login-recovery`只处理布尔观察和尝试次数，不能替代真实会话回执。

MCP主入口每页保留来源记录ID、批次、种子/层级/顺序、站点、入口、鉴权/查询锁、完整请求与响应、周期、时间、实际行数、页码及分页包络。官网备用的每个种子唯一成功官方导出至少保留：来源记录ID、批次、入口类型、种子及层级、种子顺序、站点、最近30天查询周期、过滤条件、关键词挖掘页查询身份、当前顶部/左上导出入口证据、导出任务身份、导出记录状态、触发/完成时间、页面声明总数、本轮新完成原始文件路径/哈希、实际行数和唯一机械键数。导出入口按当前可见语义确认，不绑定固定selector、坐标或DOM路径；不得用页面抄取替代完整导出。解析事件另保留原始关键词、机械键、`keywordCn`、`searchRank`、`searches`及全部seed来源身份。MCP响应还须保留页码、页内序号和分页包络。失败触发、失败任务或无效下载单独登记为技术诊断，不构成业务导出版本，不与成功结果合并；不记录账号、密码或会话内容。

## Single-export completeness gate

每个锁定种子恰好完成一个成功完整结果。官网路径是一份完整官方导出，以实际返回行数和唯一机械键闭环，页面声明总数只作证据；同一锁定种子在成功后不得为交叉重复验证再次导出。成功前发生的触发失败、任务失败或无效下载可以有界恢复，但只记诊断事件。全部种子分别满足本门后模块才完成。

MCP主路径各种子从第1页连续到短页或空页；页边界重复原始行全部保留，机械键重复另行列示。入口间续跑必须锁定相同种子、最近30天周期、过滤条件和四字段，并用稳定事件账本证明无遗漏或重复；无法证明时新建技术尝试并从第1页重启受影响种子。取得一个完整成功结果后停止。不得以手工逐页抄取网页结果作为入口。

## Four-column workbook

### 页面总数不等于已持久化人口

页面声明总数、官方导出实际非空关键词行数、唯一机械键数、明确导出上限和未解释差额分开记录；不能从恰好一个整数推断提供商上限。未解释的页面/导出差额必须保留`partial`及损失风险，不能声称完整召回或用页面总数当业务行数；已取得实际行保留，不补造缺行、不绕过官方限制抓取。主任务对允许交付范围另行验收，不回写历史已接纳文件。

只有官网备用路径，拥有任务回传前运行`../../../../scripts/source_execution.py export-population --input <本机证据.json>`；输入为`official_export{path,sha256}、sheet、keyword_column、header_row、actual_rows、page_declared_total、population_gap、completeness`。脚本直接读取官方XLSX计数，差额未解决时只允许`completeness=partial`。它不推断上限原因、不改四列字段或业务判断，也不替代查询身份、机械键及完整官方导出审查。

原有“声明总数漂移但来源实际完整”的判断保留：确有完整官方导出证据、差额已被拥有任务核实为声明总数漂移时，可提供`coverage_resolution={kind:verified_declared_total_drift,complete_export_verified:true,evidence:[{path,sha256}]}`，脚本保留差额而不因数值不同机械否决。单凭导出上限或整数行数不能使用此项，完整性理由仍由拥有任务审查；不新增重复导出或更改原召回阈值。

副任务按锁定种子顺序、页或导出行顺序机械融合所有成功结果，工作簿业务Sheet只能包含：`英文关键词`、`中文翻译`、`ABA月排名`、`月搜索量`。同一机械键跨不同种子只保留一个业务行，多值冲突时展示首次非空原值，不平均、不覆盖原始证据；事件账本、冲突组和来源指针必须保留该词的全部seed身份。工作簿、清单都记录Run相对路径、哈希、事件数、唯一词数、逐种子完成状态、失败技术尝试和损失风险。

## Handoff

回传主任务：四字段工作簿、Run相对路径、文件哈希、MCP或官网实际入口鉴权状态、入口类型、逐种子完整MCP分页证据，或官网备用唯一成功导出入口/任务/记录/完成文件证据、原始事件数、唯一词数、页面声明总数/实际行数轨迹、失败技术尝试、重复/冲突/缺失、损失风险、完整性状态和异常摘要。未登录时先单独回传`awaiting_login`，不在副任务直接向用户发问。不得回传凭据或会话内容。官方原始导出、MCP逐页响应和原始行不进入主任务消息，只保留在 `.local/runs/<Run_ID>/keyword-sellersprite-collector/`。

## Stop

一级核心缺失、细分核心状态不明、种子数量/顺序与层级锁不符、存在细分核心却遗漏一级或细分种子、出现任何额外种子时，不开始查询。MCP明确报错才允许官网备用；先由主任务提示用户登录，未登录回传`awaiting_login`并冻结本分支。两入口均失败、MCP分页完整性不能证明、入口身份无法对齐、报错、限流、结构异常、缺页、整页重复、循环、无继续进展或四字段结构性缺失时，停止受影响种子并装配已取得结果。单行字段空白保留空值，不构成整批结构错误，但必须进入缺失清单；全部锁定种子分别满足单次成功门时才能写`complete_with_residual_risk`。
