# SellerSprite expansion source contract

## Input lock

- `Run_ID`、`marketplace`、卖家精灵查询站点参数、查询月份、唯一一级品类核心大词、可选唯一产品细分核心词、两者层级/依据、锁定种子顺序、查询过滤条件、官网完整导出/MCP备用参数和本机忽略目录必须锁定。`marketplace`只允许`Amazon-US`或`Amazon-DE`；网页与MCP站点参数必须匹配，发现不一致时记录`marketplace_mismatch`、停止并通知用户介入，不得静默改成US。
- 存在已确认产品细分核心词时，种子按`一级品类核心大词、产品细分核心词`锁定为两个；不存在时只锁定一级品类核心大词。每个种子只取得一个成功完整结果；本 Skill 不增加、替换、遗漏、追加或语义合并种子，强等价、宽泛、卖点、配置和场景表达不得成为额外种子。
- 业务字段固定映射为`keyword,keywordCn,searchRank,searches`；MCP备用的`returnFields`固定为这四项，网页原始导出可保留提供商原字段，但业务工作簿不得增加字段。
- 首选本长期副任务内置浏览器中的已登录卖家精灵官网及其完整官方导出；每Run在任何查询或导出动作前验证会话与站点，不读取或留存凭据。未登录时副任务只向主任务回传`awaiting_login`并冻结，由主任务提示用户登录；未登录本身不得触发MCP。只有已登录但官网完整导出链路仍不可用时才允许同一卖家精灵提供商MCP。入口切换必须保持相同站点、月份、种子、过滤条件和四字段口径。
- 本阶段来源优先级只允许`卖家精灵网页完整官方导出 > 卖家精灵MCP`。Sorftime官网只是账户/MCP配置入口，Sorftime网页和MCP均不得用于关键词挖掘或替代卖家精灵结果。

## Raw export and page record

每个种子的唯一成功官方导出至少保留：来源记录ID、批次、入口类型、种子及层级、种子顺序、站点、查询月份、过滤条件、关键词挖掘页查询身份、当前顶部/左上导出入口证据、导出任务身份、导出记录状态、触发/完成时间、页面声明总数、本轮新完成原始文件路径/哈希、实际行数和唯一机械键数。导出入口按当前可见语义确认，不绑定固定selector、坐标或DOM路径；不得用页面抄取替代完整导出。解析事件另保留原始关键词、机械键、`keywordCn`、`searchRank`、`searches`及全部seed来源身份。MCP备用响应还须保留页码、页内序号和分页包络。失败触发、失败任务或无效下载单独登记为技术诊断，不构成业务导出版本，不与成功结果合并；不记录账号、密码或会话内容。

## Single-export completeness gate

每个锁定种子恰好完成一个成功完整结果。官网路径是一份完整官方导出，以实际返回行数和唯一机械键闭环，页面声明总数只作证据；同一锁定种子在成功后不得为交叉重复验证再次导出。成功前发生的触发失败、任务失败或无效下载可以有界恢复，但只记诊断事件。全部种子分别满足本门后模块才完成。

只有已登录且官网完整导出链路不可用、MCP完整性仍可证明时，才允许受影响种子从第1页连续到短页或空页；页边界重复原始行全部保留，机械键重复另行列示。入口间续跑必须锁定相同种子、月份、过滤条件和四字段，并用稳定事件账本证明无遗漏或重复；无法证明时新建技术尝试并从第1页重启受影响种子。取得一个完整成功结果后停止。不得以手工逐页抄取网页结果作为入口。

## Four-column workbook

副任务按锁定种子顺序、页或导出行顺序机械融合所有成功结果，工作簿业务Sheet只能包含：`英文关键词`、`中文翻译`、`ABA月排名`、`月搜索量`。同一机械键跨不同种子只保留一个业务行，多值冲突时展示首次非空原值，不平均、不覆盖原始证据；事件账本、冲突组和来源指针必须保留该词的全部seed身份。工作簿、清单都记录Run相对路径、哈希、事件数、唯一词数、逐种子完成状态、失败技术尝试和损失风险。

## Handoff

回传主任务：四字段工作簿、Run相对路径、文件哈希、网页登录会话验证状态、入口类型、逐种子唯一成功官方导出入口/任务/记录/完成文件证据、原始事件数、唯一词数、页面声明总数/实际行数轨迹、失败技术尝试、重复/冲突/缺失、损失风险、完整性状态和异常摘要。未登录时先单独回传`awaiting_login`，不在副任务直接向用户发问。不得回传凭据或会话内容。官方原始导出、MCP逐页响应和原始行不进入主任务消息，只保留在 `.local/runs/<Run_ID>/keyword-sellersprite-collector/`。

## Stop

一级核心缺失、细分核心状态不明、种子数量/顺序与层级锁不符、存在细分核心却遗漏一级或细分种子、出现任何额外种子时，不开始查询。未登录时回传主任务`awaiting_login`并冻结，未登录不得启用MCP。已登录后官网完整导出链路与同提供商MCP均不可用、MCP分页完整性不能证明、入口身份无法对齐、报错、限流、结构异常、缺页、整页重复、循环、无继续进展或四字段结构性缺失时，停止受影响种子并装配已取得结果。单行字段空白保留空值，不构成整批结构错误，但必须进入缺失清单；全部锁定种子分别满足单次成功门时才能写`complete_with_residual_risk`。
