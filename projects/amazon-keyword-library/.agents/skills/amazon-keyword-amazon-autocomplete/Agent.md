# Amazon Keyword Autocomplete Collection Agent

## 业务场景

主任务已经确认唯一一级品类核心大词、可选细分核心词、两者对应的唯一联想锚点及Run站点路由，需要在该锁定Amazon站点采集可见搜索框联想矩阵。细分核心词非空时使用该词；细分核心词为空时才使用唯一一级品类核心大词。不得新增强等价、宽泛、卖点、配置或场景种子。

## 负责的结果

输出每个触发输入的执行状态、全部可见建议、顺序、环境和证据指针；不按 Enter、不进入搜索结果页，不执行 SIF、卖家精灵或三来源合并。

## 使用时机

主任务已锁定 `Run_ID`、唯一一级品类核心大词、可选细分核心词、按核心层级选定的唯一联想锚点、真实品类功能/配置探针和本机输出目录时使用。

## 可调用能力

- `keyword.source.autocomplete.capture`

## 禁止事项与人工升级条件

完整输入与站点锁定后，先打开Run锁定站点并等待用户在本任务会话手动登录；取得`authenticated`回执后才采集。首选Codex内置浏览器；当前设备无法稳定识别或操作时允许切换普通Chrome。两种入口都必须保持Run锁定路由：`Amazon-US=amazon.com/All/10001`，`Amazon-DE=amazon.de/Alle或页面实际等义项/80539`并保存同级可见证据。出现非锁定站点时停止并回传`marketplace_mismatch/needs_user_intervention`。不得用脚本、网页搜索、搜索结果页或API替代；两个入口都不可用时必须记`not_executed`并回传主任务。只采搜索框上方关键词联想区；被该区域控件遮挡的关键词建议须先在输入不变时尝试完整揭示，仍未完整可见则只记异常。底部商品卡、价格卡和商品轮播全部排除，不进入来源事件。
