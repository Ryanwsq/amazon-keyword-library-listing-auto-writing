# SIF competitor source contract

## Input lock

- `Run_ID`、`marketplace`、提供商查询站点参数、原始竞品清单、竞品产品类型映射、最终获准竞品清单、排除清单/理由和本机忽略输出目录必须锁定。`marketplace`只允许`Amazon-US`或`Amazon-DE`，提供商参数必须与Run站点一致；不一致时记录`marketplace_mismatch`、停止并通知用户介入，不得静默改成US。原始竞品不超过5个时全部保留；超过5个时按稳定竞品产品类型分组，每类机械保留输入顺序中的第一个有效ASIN。类型无法可靠确认，或每类取一后仍超过5个时，必须在查询前回传主任务阻断，不得自行丢弃某一类型。
- 每个竞品单独查询；父体无数据时只记录问题并由主任务决定是否补充获准子体。
- 查询口径固定最近30天，请求已确认的每 ASIN 300条适配器上限。
- 新运行入口固定 **SIF MCP > SIF官网**，标记`source_policies.sif_competitor=mcp-first-error-only-20260914`。首次查询前验证当前Run/Task/host的SIF MCP真实鉴权及查询锁，取得`authenticated_mcp`；不要求先网页登录、先官网失败或额外逐Run的MCP例外批准。输入表中的网页登录选择只是备用偏好，不改变来源顺序。
- 仅真实MCP明确报错才按共享入口合同保存错误与未完成人口，主任务提示用户登录对应任务的SIF官网，真实网站认证后执行备用。零、缺字段、截断/不完整不是报错，不自动换入口；错站、权限不明、账户冲突/验证码需用户介入，不绕过权限。

## Persisted response

### MCP优先与受控官网备用

完整读取`../../../../docs/mcp-first-source-access.md`：新派发使用v2 source_access、mcp_error唯一降级原因、原查询锁、未完成人口、原始报错和用户登录通知及网站认证；运行source-access --stage sif核验。原20260911 v1仅兼容历史锁，不用于新派发。官网新查询锁写入locks.sif_query_lock_sha256，旧执行关闭后才新派发；不得覆盖历史envelope。七列、每ASIN300条、最近30天与原始证据门不变。

### 一次已自动填充登录恢复

本任务此前已通过认证、随后跳回同一提供商登录页，且密码管理器已经填满账号和密码框时，允许只点击一次Login并重新核验提供商、账户身份、站点和查询锁。只观察非敏感的“已填充/未填充”状态，绝不读取、显示、复制、导出、记录、修改或补填凭据；无法不读取值而确认填充状态时，交用户。空白或部分填充、验证码/MFA、失败、错账户/站点、再次跳转都保持`awaiting_login`并由主任务引导用户。Amazon仍由用户登录。可用`source_execution.py login-recovery`验证仅布尔观察字段和一次尝试预算；它不点击界面，不生成登录完成回执。

每次MCP调用至少保存：来源记录ID、批次、竞品ASIN、站点、入口类型、当前鉴权证明指针、全部请求参数、查询窗口、来源返回日期/截止日、抓取时间、返回行数、原始响应指针和完整返回。官网备用同样保留这些身份字段、入口切换原因、完整页面/官方导出原始证据、可见结果顺序和数量闭环。来源不返回准确起始日时写`来源未返回`；不能宣称来源侧已缩减未提供的字段。任何入口的原始证据均须先保存再解析，保存失败立即停止受影响查询。

## Minimal workbook

数据不完整只记录缺口或技术异常，不是MCP报错，不允许自动官网备用；原允许的单行ABA/搜索量/Top3缺失、来源未返回起始日及真实零结果不触发重采、入口切换或跨入口补值。不得用“补齐七列的每个值”取代七列映射与缺失留空合同。

七列明细固定为：`竞品ASIN`、`SIF返回序号`、`英文关键词`、`ABA排名`、`搜索量`、`Top3点击份额`、`Top3转化份额`。每个竞品返回记录均保留一行，不按相关性删除。核心词候选摘要可按机械键计算竞品覆盖数、最佳/中位返回序号和字段冲突，但不得确认一级品类核心大词、产品细分核心词、主执行锚点或强等价表达。高覆盖、高返回位置、高ABA或高搜索量只描述竞品流量证据，不表示产品对象等价或核心层级。

## Handoff

回传主任务：工作簿、Run相对路径、文件哈希、原始/入选/排除竞品清单、逐ASIN产品类型和排除理由、逐竞品入口类型/返回行数、七列明细行数、核心词候选数、字段缺失/冲突、原始证据清单指针、异常和完成状态。未登录时先单独回传`awaiting_login`，不在副任务直接向用户发问。原始业务响应正文只保留在 `.local/runs/<Run_ID>/keyword-sif-collector/`，不进入主任务消息。

## Gate

原始/入选/排除ASIN人口先闭合；超过5个时每类只保留输入顺序中的第一个有效ASIN。每个成功查询均有入口类型、完整原始证据、参数、时间、周期、行数和本机指针；七列工作簿与原始记录数量可回查；失败竞品有准确原因。新Run先MCP，官网备用必须有当前Run/Task/host的MCP故障原因、原查询锁、未完成人口和网站登录证明；只有已网页登录不能跳过MCP。入口间续跑必须证明相同查询身份且无遗漏/重复，不得把网页与MCP混成无身份续采；无法证明时新建批次从头查询受影响ASIN。ASIN类型无法确认、每类取一后仍超过5个、任一证据未保存、站点/父子体不明、结构冲突、授权/鉴权不明或备用条件未满足时回传`blocked/incomplete`，但不得抹去其他竞品已取得结果。
