# Amazon 关键词库知识库 V0.1（历史工作草案）

> 注意：本文件保留第一轮完整工作草案，仅供参考，不再作为持续更新的主知识库。后续唯一主文档为 `Amazon产品关键词库知识库.md`；其中未逐项确认的细则不得视为正式规则。

> 适用范围：Amazon US 产品关键词研究。当前版本用于统一“关键词收集 → 关键词清洗 → 关键词分类”的步骤、判断依据、输出字段与复核节点。

## 一、总原则

关键词库不是一张“搜索量从高到低”的词表，而是三层数据：

1. **原始候选池**：尽量完整地记录从 ABA、搜索框、竞品反查、自有广告等来源取得的原词和来源证据。
2. **清洗主表**：统一词形、去重，并根据产品事实和用户搜索意图判断精准、关联、补充或剔除。
3. **分类应用表**：在通过清洗的词上增加词义、竞争性、趋势性和使用渠道标签。

必须遵守的四条边界：

- **相关性不由搜索量决定**。高流量不能把无关词变成相关词。
- **相关性等级与证据可信度分开**。词可以很精准，但因数据源单一而只有低可信度。
- **产品事实是一票否决项**。包含产品不具备的功能、材质、尺寸、兼容性、认证或人群承诺时，不得降级为关联词继续使用。
- **保留原始数据**。清洗不能覆盖原词、原始指标、来源 ASIN、站点和采集时间。

## 二、完整流程

### 阶段 0：建立产品边界卡

在找词前先填产品边界卡，否则无法判断应该反查哪些产品，也无法进行相关性清洗。

| 字段 | 必填内容 | 判断用途 |
|---|---|---|
| 站点与语言 | 如 US / English | 限定搜索框、ABA、SERP 和词形处理范围 |
| 核心产品名 | 买家对产品的通用称呼，不写品牌 | 判断精准词的产品身份 |
| 核心功能 | 产品主要解决什么问题 | 区分同类产品与相邻替代品 |
| 产品形态 | 独立产品、配件、耗材、套装、兼容件等 | 决定竞品选取半径 |
| 硬性规格 | 尺寸、承重、材质、接口、型号、数量等 | 排除不准确的属性词 |
| 兼容边界 | 适配与不适配对象 | 兼容类产品的一票否决项 |
| 核心人群/场景 | 已有事实支持的人群和场景 | 判断关联词和补充词 |
| 变体边界 | 父体共享属性与子体独有属性 | 防止把子体属性污染父体词库 |
| 风险边界 | 医疗、认证、环保、竞品品牌、IP 等 | 建立风险词/禁用词标签 |
| 价格带 | 当前产品和目标竞品的正常成交价区间 | 识别不同购买层级的伪竞品 |

**阶段门：**产品边界卡未确认，不进入竞品反查和相关性定级。

## 三、板块一：关键词收集

### 3.1 先确定产品选取范围

所有候选产品或 ASIN 先分层，再决定其关键词可以进入哪个池。

| 层级 | 定义 | 必要条件 | 允许进入的关键词池 |
|---|---|---|---|
| P0 直接同类 | 买家搜索同一个核心产品，功能和形态相同，关键约束基本一致 | 核心产品名、核心功能、产品形态均一致 | 精准候选池 |
| P1 近邻同类 | 同一核心产品和功能，但尺寸、材质、结构、目标人群或价格带存在差异 | 产品身份相同；差异不能改变主要购买目的 | 精准候选池 + 属性扩展池 |
| P2 相邻替代/共用场景 | 解决相同问题或用于相同场景，但产品身份或形态不同 | 买家确实可能在两者之间比较或替代 | 关联候选池；不能直接作为精准词来源 |
| P3 噪声产品 | 仅外观、单个词根或泛场景相似，购买目的不同 | 不满足 P0–P2 | 排除；记录噪声原因 |

#### 不同产品类型的选取重点

| 产品类型 | 选取范围 | 特别判断依据 |
|---|---|---|
| 成熟标准品 | P0 为主，P1 用于属性扩展 | SERP 主流产品形态是否一致；关键规格是否可比 |
| 多用途/混合型产品 | 分别建立“主用途 P0”和“次用途 P1/P2” | 不能因产品可用于某场景，就把该场景下所有产品当直接竞品 |
| 配件/兼容件 | 同一配件类型 + 同一宿主产品/型号范围 | 兼容对象、接口、尺寸和安装方式优先于外观相似 |
| 耗材/替换件 | 同一消耗目的 + 同一规格/适配标准 | 型号、规格和消耗周期错误时直接排除 |
| 套装产品 | 同套装购买目的的产品优先；拆分组件另设补充池 | 单个组件词不能自动视为整套产品精准词 |
| 创新品/新品类 | P0 少时，扩大到 P2 的问题词、解决方案词和替代品 | 必须把“产品身份词”和“需求探索词”分开保存 |
| 季节/主题产品 | 基础功能同类优先，季节或主题作为属性层 | 不能用主题相似替代功能相同 |
| 强变体产品 | 先建父体共享词池，再建子体属性词池 | 颜色、尺寸、数量、兼容型号等只进入对应子体 |

#### 产品层级判定顺序

1. 核心产品身份是否相同？
2. 主要购买目的是否相同？
3. 产品形态和使用方式是否相同？
4. 是否满足本产品的硬性规格/兼容边界？
5. 价格带和目标人群差异是否已经改变购买层级？

前 3 项都相同，通常进入 P0；前 2 项相同但后续有一项明显差异，通常进入 P1；仅需求或场景相同，进入 P2；购买目的不同，进入 P3。

### 3.2 四类收集来源

#### A. ABA

用途：建立站点级真实搜索需求池、观察搜索频率位置和跨期变化。

操作步骤：

1. 用核心产品名、同义词、常用缩写建立种子词。
2. 从种子词提取产品词根、属性词根、场景词根和人群词根。
3. 逐轮扩展并记录 ABA 排名、报告周期、站点和来源种子词。
4. 与 P0/P1 产品反查结果交叉验证。

**“ABA 前 100 万”口径：**

- 将前 100 万作为默认的**需求候选入口**，不能作为相关性结论。
- 排名在 100 万以内的无关词仍须剔除。
- 排名在 100 万以外或无排名的词，如有自有广告成交、Search Query Performance 或多个 P0 竞品支持，仍可保留为长尾词。
- 最终停止扩词看“新增有效词率”，不只看排名。连续一轮新增词中，通过相关性清洗的词低于 10%，且没有新的词根/搜索意图时，停止该分支。

#### B. Amazon 搜索框联想

用途：发现买家自然表达、长尾组合、拼写变体和近期需求方向。

种子组合矩阵：

- 核心产品名
- 核心产品名 + 功能/属性
- 核心产品名 + 人群
- 核心产品名 + 场景
- 核心产品名 + 尺寸/材质/兼容对象
- 问题/需求 + 产品词

记录时必须保留：完整联想词、输入种子、采集日期、站点、是否登录/地区环境。搜索框联想只证明“出现过该表达”，不单独证明搜索量、竞争性或转化价值。

#### C. 竞品反查

用途：从 P0/P1 产品的实际流量结构中补足词库。

操作步骤：

1. 先按 P0/P1/P2 标注 ASIN，不允许把所有外观相似商品一起反查。
2. P0 用于发现核心精准词；P1 用于发现属性、人群和规格长尾；P2 只用于关联需求探索。
3. 每个词记录来源 ASIN 数、来源层级、自然/广告来源和对应排名或流量指标。
4. 同一个词被多个 ASIN 或多个工具重复发现时，合并为一条，但保留来源覆盖数。

**停止条件：**新增一个同层级 ASIN 后，新增的有效关键词低于 5%，且没有新增核心词根时，停止继续增加同类 ASIN。该阈值是 V0.1 默认值，需用实际类目校准。

#### D. 自有广告与品牌数据

用途：补充“已经产生点击或转化”的真实买家查询，并验证候选词价值。

- 搜索词报告中的 customer search term 与投放 keyword/target 必须分栏，不能混为一列。
- 同一搜索词跨广告活动、广告组或展示位置汇总时，先按 query 聚合，避免重复计算。
- 广告搜索词报告只覆盖至少产生过一次广告点击的搜索词，因此“报告中没有”不等于“没有市场需求”。
- 有成交的低搜索量长尾词可越过 ABA 前 100 万门槛，但仍必须通过产品事实和相关性判断。

### 3.3 收集阶段输出字段

| 字段组 | 建议字段 |
|---|---|
| 标识 | keyword_id、raw_keyword、marketplace、language |
| 来源 | source_type、source_detail、seed_keyword、source_asin、asin_tier |
| 原始指标 | ABA_rank、search_volume、organic_rank、ad_rank、clicks、orders、sales、CPC 等 |
| 时间 | collected_at、data_start、data_end、time_granularity |
| 追溯 | source_file、source_row、collector、notes |

## 四、板块二：关键词清洗

### 4.1 清洗顺序

清洗必须按以下顺序执行：

1. **格式标准化**：大小写、首尾空格、重复空格、标点和明显乱码。
2. **语言与站点检查**：非目标语言、非目标站点表达单独标记，不直接混入主表。
3. **词面去重**：完全重复词合并。
4. **词族归并**：单复数、词序、拼写变体、常见缩写归入同一 keyword_family，但保留每个原始短语。
5. **产品范围清洗**：根据 P0–P3 和产品边界卡去掉跨品类噪声。
6. **事实准确性检查**：功能、材质、规格、兼容、认证、人群承诺是否真实。
7. **相关性定级**：精准词、关联词、补充词、剔除词。
8. **风险检查**：竞品品牌、商标、医疗/安全/环保等高风险表达单独标记。

### 4.2 相关性四级定义

这四级是**互斥的主标签**；词义标签可以多选。

| 主标签 | 定义 | 判断问题 | 可否单独代表产品购买意图 | 默认用途 |
|---|---|---|---|---|
| R1 精准词 | 搜索者主要期待的就是本类产品，且词中所有限定条件均由产品事实支持 | “搜索这个词的人，看到本产品是否无需改变购买目标？” | 可以 | Listing 核心字段、SEO、核心广告 |
| R2 关联词 | 与产品存在明确的用途、场景、功能、人群或替代关系，但搜索结果或购买目标不只指向本产品 | “产品能合理满足该需求，但它是不是唯一或主要产品答案？” | 部分可以，但意图较宽或较偏 | Bullet/A+、探索广告、内容扩展 |
| R3 补充词 | 单独不能稳定表示产品身份，但能补充属性、风格、规格、人群、场景或问题表达 | “它是否必须和核心产品词组合后才有明确购买意义？” | 通常不可以 | 组合长尾、文案表达、词根扩展 |
| RX 剔除/风险词 | 产品不具备该属性，购买目的不同，语义过远，或存在不可接受的合规/IP 风险 | “使用该词是否会造成错误预期或不合规表达？” | 不可以 | 否定词、禁用词、噪声库 |

#### 判断决策树

1. **事实是否支持？**不支持 → RX“不准确”。不能降级为 R2。
2. **该词是否直接指向本类产品？**是 → 检查搜索结果和购买目的；一致则 R1。
3. **是否存在明确、可解释的用途/场景/人群/替代关系？**是 → R2。
4. **是否属于必须与产品词组合的属性、风格、规格、场景或人群修饰词？**是 → R3。
5. 其余 → RX“无关/过远”。

#### 三类容易误判的边界

- **属性准确但产品身份不完整**：如单独的颜色、材质、尺寸，多数是 R3；与核心产品词组合且事实支持后，完整短语可以成为 R1。
- **同场景不等于同产品**：共同出现在 home office、camping、baby 等场景，只证明可能相关，通常为 R2 或 RX。
- **不具备的功能不是关联词**：产品没有 massage 功能时，`massage + 产品词` 应为 RX，而不是 R2。

### 4.3 相关性与证据可信度分开记录

相关性主标签由语义和购买意图决定；证据等级说明结论有多可靠。

| 证据等级 | 默认标准 |
|---|---|
| E3 高 | 产品事实通过，且至少两类独立来源支持；其中至少一类为 Amazon 行为数据，如 ABA、Search Query Performance、自有广告搜索词 |
| E2 中 | 产品事实通过，且一个强来源或两个弱来源支持 |
| E1 低 | 仅搜索框联想、单个竞品或人工词义判断支持，尚无行为/表现数据 |
| E0 待核 | 产品事实、搜索意图或来源记录不完整 |

同一个词可以是 `R1 + E1`：语义非常精准，但需求证据不足；也可以是 `R2 + E3`：市场关系很明确，但不是直接产品词。

### 4.4 范围清洗与去重规则

- 完全相同短语：合并成一条，来源与指标不丢失。
- 单复数、词序和拼写变体：建立同一词族，但保留短语级记录，避免损失广告匹配和买家表达差异。
- 同义词：归入同一语义词族，不直接删除低频表达。
- 品牌词：自有品牌、竞品品牌、泛品牌意图分开；竞品品牌默认不得进入 Listing 文案词池。
- ASIN 字符串：从广告搜索词中单独分为商品投放/详情页流量，不计入普通关键词词频。
- 不同站点语言混用：放入本地化待审池，不与英文主词库直接合并。

### 4.5 清洗阶段输出字段

| 字段组 | 建议字段 |
|---|---|
| 标准化 | normalized_keyword、keyword_family、variant_type |
| 审核结果 | cleaning_status、relevance_level、relevance_reason_code |
| 事实依据 | supported_fact、unsupported_claim、compatibility_check |
| 证据 | evidence_level、source_count、source_type_count |
| 风险 | brand_flag、ip_flag、compliance_flag、negative_keyword_flag |
| 审核追踪 | reviewer、reviewed_at、review_note |

建议原因码：`DIRECT_PRODUCT`、`ATTRIBUTE_SUPPORTED`、`USE_CASE_RELATED`、`ADJACENT_ALTERNATIVE`、`MODIFIER_ONLY`、`UNSUPPORTED_FEATURE`、`WRONG_COMPATIBILITY`、`WRONG_PRODUCT`、`TOO_BROAD`、`BRAND_IP`、`COMPLIANCE_RISK`。

## 五、板块三：关键词分类

清洗通过后再分类。分类不能反过来改变相关性结论。

### 5.1 词性/词义分类

#### 短语级语义标签（可多选）

- 核心品类词
- 产品同义词/缩写
- 功能词
- 属性词
- 规格/尺寸词
- 材质词
- 结构词
- 人群词
- 场景词
- 痛点/需求词
- 效果/利益词
- 风格/颜色/主题词
- 配件/套装词
- 兼容/型号词
- 品牌词
- 问题式/比较式词

#### 单词/双词词频

词频必须在“清洗通过的 canonical keyword”上统计，不能直接对原始反查表计数。

同时输出三种指标：

1. **短语覆盖频次**：含该单词或双词组合的独立关键词数量。
2. **来源覆盖数**：该词根出现在多少类来源、多少个 P0/P1 ASIN。
3. **需求加权频次**：按 ABA/搜索量等需求指标加权后的覆盖，不等同于简单出现次数。

停用词、品牌词和 ASIN 字符串单独处理。同义词可以按词族汇总，但必须保留原始词面统计。

### 5.2 竞争性分类

**高搜索量不等于高竞争。**竞争性至少拆成三个维度：

| 维度 | 可用证据 | 说明 |
|---|---|---|
| 需求强度 | ABA 排名、搜索量、Search Query Performance query volume | 表示市场需求，不直接表示竞争 |
| 自然竞争 | SERP 高相关商品数、头部点击/转化集中度、头部商品销量/评论壁垒、自然位稳定度 | 判断自然排名难度 |
| 广告竞争 | 建议竞价、实际 CPC、广告位密度、搜索词展示份额/排名 | 判断付费流量成本与争夺程度 |

默认分类规则：

- 至少有两个竞争维度的数据，才能给出高/中/低结论。
- 只有需求数据时，标记“需求高/中/低，竞争未知”。
- 竞争结论必须附周期和站点；不能把一次 SERP 截图作为长期结论。
- 最终用“需求 × 竞争”二维矩阵决定机会类型，例如高需求高竞争、低需求低竞争，而不是把所有词压成一个总分。

### 5.3 趋势性分类

比较前提：同一站点、同一精确关键词、同一指标口径、相同时间粒度。词族趋势作为第二层分析，不能替代精确短语趋势。

建议至少保留：近 4 周、前 4 周、近 13 周，以及去年同期（有数据时）。

| 趋势标签 | V0.1 默认判断 |
|---|---|
| 上升 | 近 4 周需求中位数较前 4 周提升 ≥20%，且至少 3 周方向一致 |
| 下降 | 近 4 周需求中位数较前 4 周下降 ≥20%，且至少 3 周方向一致 |
| 稳定 | 两期中位数变化在 ±15% 内，且波动没有明显扩大 |
| 波动 | 变化方向反复，或周期内变异系数明显偏高，无法形成单向趋势 |
| 季节性 | 在相同月份/季度重复出现峰谷，或有明确节日、天气、开学等周期证据 |
| 新兴 | 前期无有效需求记录，之后连续多个周期出现并增长 |
| 待判断 | 周期太短、数据缺口大或指标口径变化 |

如果使用 ABA 排名，数字越小代表需求位置越靠前；应先转换为同向的需求指数或用排名改善/恶化描述，不能把“排名数字变大”写成增长。

以上百分比是 V0.1 操作阈值，不是 Amazon 官方标准。完成不同类型的样本产品后，应按类目波动重新校准。

## 六、三个阶段的质检门

### 收集完成

- 产品边界卡已确认。
- 每个来源词都能追溯到来源、时间、站点和种子/ASIN。
- 竞品 ASIN 已按 P0–P3 分层。
- 连续扩展达到停止条件，且没有新的核心词根或搜索意图。

### 清洗完成

- 原始词、标准词和词族三层均保留。
- 每个词都有 R1/R2/R3/RX 主标签和原因码。
- 涉及功能、规格、兼容性和合规承诺的词已核对产品事实。
- 相关性和证据等级分别记录。
- 被剔除的词没有删除，而是进入噪声/否定/风险库。

### 分类完成

- 所有分类只针对清洗通过词。
- 词义允许多标签，相关性主标签保持唯一。
- 竞争性没有用搜索量单独判断。
- 趋势比较口径一致，周期与阈值可追溯。

## 八、下一轮需要用案例校准的四个问题

1. P0/P1/P2 的边界能否在成熟标准品、配件和创新品上稳定复现？
2. `ABA 前 100 万 + 例外证据`是否适合现有类目，还是需要按类目设置不同入口？
3. R1/R2/R3 对容易混淆的场景词、属性词和替代品词能否达成一致判断？
4. 趋势阈值 15%/20% 和收集停止阈值 5%/10% 是否需要按类目波动调整？

建议选 3 个差异明显的真实产品做校准：一个成熟标准品、一个配件/兼容型产品、一个创新或强季节性产品。每个产品随机抽取 50–100 个候选词进行双人独立标注；对不一致词补充规则与正反例，形成正式 V1.0。
