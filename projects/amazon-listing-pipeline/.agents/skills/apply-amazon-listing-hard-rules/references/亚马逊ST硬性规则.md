# Amazon 后台 Search Terms 硬性规则

> 适用范围：Run锁定站点的 `Search Terms` / `generic_keywords` 字段；下列249 bytes是美国站规则，德国站不得静默套用
> 规则冲突时，以当前站点、商品类型、后台字段、上传模板、Processing Summary 及错误提示中的更严格限制为准。

## 1. 字节上限

- Amazon-US后台未显示更严格限制时，整个 `generic_keywords` 属性必须小于 250 bytes，即最多249 bytes。Amazon-DE必须先锁定当前德国站后台或类目规则的可核验上限；未核验时保持待确认，不得用249冒充德国站规则。
- 当前上传模板、处理报告或错误提示要求小于 200 bytes 时，最多 199 bytes。
- 上限按整个字段计算，不是按单词或词组分别计算。
- 必须按最终文本的 UTF-8 字节数校验，不得用字符数代替字节数。
- 超过适用上限时，Amazon 可能忽略整个字段。

## 2. 格式

- 使用小写字母。
- 单词之间只能使用一个普通空格。
- 不得使用逗号、分号、冒号、连字符或其他标点作为分隔符。
- 不得使用项目符号、Emoji、HTML、JavaScript 或其他特殊格式。
- 不得写完整营销句，不得添加标题、标签或说明文字。
- 不得保留首尾空格或连续多个空格。

## 3. 真实性与相关性

- 所有词必须与当前商品真实相关。
- 不得填写商品不具备的品类、功能、材质、用途、适用人群或其他误导性信息。
- 不得使用 Search Terms 规避标题、属性或商品详情页的真实性及合规要求。

## 4. 禁止内容

- 自有品牌、竞争品牌、其他公司、产品线或商标名称，以及故意拆写、错拼或变形的品牌名称。
- 自有或竞争对手的 ASIN，以及拆分、变形或规避识别的 ASIN。
- 内部 SKU、内部型号记录或商品管理备注。
- `new`、`sale`、`on sale now`、`limited time`、`available now` 等临时性、促销性、库存或时效陈述。
- `best`、`cheapest`、`amazing`、`top rated`、`number one`、`perfect` 等主观、排名、价格优势、最高级、比较性或无法证明的宣传词。
- 与违法活动、仇恨、暴力、歧视、辱骂、冒犯或其他违规内容有关的词。

## 5. 提交前硬性检查

- UTF-8 字节数未超过当前适用上限。
- 格式仅含合规的小写词和单个空格。
- 所有词均与当前商品真实相关。
- 不含品牌、ASIN、临时性陈述、主观宣传词或其他禁止内容。
