# orchestrate-amazon-listing-pipeline

## 业务场景

总控、跨项目交接、两道人机确认、07/09与最终交付验收。完整SOP见[SKILL.md](SKILL.md)。

## 负责的结果

07信息校准、09映射、双确认门和10交付验收。不替代其他模块的结果或人工确认。

## 使用时机

本模块收到明确分发的角色、Run/SKU、规则版本、输入路径与SHA-256和启动授权后。输入：含必填`marketplace`及`登录准备`的锁定产品输入或01–05封存包、独立06、固定八会话矩阵的逐任务登录回执及用户确认记录。只读初始化时不启动业务。

## 可调用能力

- `listing.main.execute`：登记于[capabilities.yaml](capabilities.yaml)；状态planned不表示已验证可用，实际工具按原SOP和当次授权确认。

## 禁止事项与人工升级条件

不扩大角色权限、不改历史Run、不以参考Skill代替执行模块、不以技术失败或未知填0、不代用户确认。账户密码、验证码、Cookie和令牌不得进入输入表、派发文本、证据或Git。输入冲突、来源/哈希变化、规则缺失或当前模块规定的访问阻断时，按原SOP停止受影响动作并回主任务。各模块自己的问题、次数、停止与重试合同原样保留，不套统一重试规则。

资料读取路由和完整判断边界在[知识索引](knowledge/index.md)及原SOP中。包拆分不改变既有项目内验收；新结构revision的证据登记见[evidence/index.md](evidence/index.md)。
