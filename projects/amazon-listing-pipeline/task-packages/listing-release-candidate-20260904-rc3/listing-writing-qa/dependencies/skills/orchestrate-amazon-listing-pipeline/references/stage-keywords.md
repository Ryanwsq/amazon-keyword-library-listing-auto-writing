# 阶段：跨项目关键词生产与SKU终筛

## 目标

把本项目锁定的产品基础输入发送给 `Amazon关键词词库｜主任务｜main`；该项目完成后把完整关键词总工作簿回传至本项目 `副线程｜SKU可用关键词库`，由后者完成最终 SKU 事实匹配和文本质量清理。总控只调度、等待、登记和校验，不复制两个负责模块的业务规则。

发送或接收前完整读取[关键词交接合同](keyword-handoff-contract.md)，使用协议`AKW-LISTING-INTERFACE-v1`及双方当前合同哈希。三组输入、类目、细分回答、原始直接竞品及当前事实锁作为独立附加对象传递，不改变Alexa三表。

## 绑定顺序

1. 主线程按交接合同锁定三组原始输入、目标类目、用户确认的多稳定产品类型细分是/否、站点、品牌/当前SKU身份、原顺序直接竞品及类型证据，保存输入与附加对象来源 SHA-256。核心词及代表ASIN筛选归关键词主任务。
2. 向 `Amazon关键词词库｜主任务｜main` 下发锁定文件和 Listing Run_ID，等待其返回关键词项目 Run_ID 与正式输出路径。
3. 等待 Amazon 关键词主任务把完整关键词总工作簿、产品身份、路径、SHA-256 和交付状态回传给本项目 `副线程｜SKU可用关键词库`，并向主线程返回交接回执。
4. 总表可先供SKU预接收，但正式回执必须回主线程；主线程校验双方Run/revision、当前事实锁、总表与过程manifest哈希、XLSX完整性、人口/缺口及真实上游状态后，才下发本Run的READY启动标志。SKU预接收或关键词项目通知不能代替此门，也不得改用其他文件。
5. 接收 SKU 副线程输出，校验 XLSX 完整性、五类 Sheet 契约及 `SKU可用关键词库` 五字段。
6. 与初始输入及 01–05 的 ASIN、SKU、产品类型和事实卡闭环；不一致即阻断。
7. 复制并登记为 `06_SKU可用关键词库.xlsx`，同时保留两段交接的来源路径、Run_ID 和哈希。
8. 任一上游尚未完成时将 `keywords` 置为 `needs_input`；不得跳过 SKU 副线程、直接使用总工作簿或补造指标、词条。

## 输入

### 下发给 Amazon 关键词项目

- 按交接合同完整发送`input_groups、product_context、direct_competitors_raw`及Run/revision、授权、合同与来源锁；已提供字段直接映射，不另索取核心词；未知保留未知。
- 三组输入来源、类目及细分确认必须可定位；稳定类型证据不足由关键词项目按其原筛选规则处理，不在Listing补造类型或预筛。

### Amazon 关键词项目回传

- 正式完整关键词总工作簿；
- 双方Run/revision、当前产品事实锁、总表及过程manifest指针/哈希、人口与缺失证据、数据血缘、原交付/独立QA/P1状态，按交接合同回主线程。

### SKU副线程回传

- 完成 SKU 事实终筛和文本质量清理的工作簿；
- SKU 处理 Run_ID（若有）、产品身份、输出路径和 SHA-256；
- 01–05 封存包或 `full_pipeline` 锁定输入中的本品身份，用于最终闭环。

## 最低兼容输出

工作簿至少包含 Sheet `SKU可用关键词库`，列名：

`关键词分类｜关键词｜中文翻译｜月搜索量｜ABA月排名`

还必须保留以下附加 Sheet（名称以独立 Skill 的锁定合同为准）：

- `品类产品通用词库`
- `词频统计`
- `关键词竞争性分析`
- `关键词趋势性分析`

最终保存为 `06_SKU可用关键词库.xlsx`。

## 数据规则

- 关键词必须与当前 SKU 真实相关，不能因为竞品拥有某功能就判本品可用。
- 月搜索量和 ABA 排名必须为数值或空白；缺失不能补 0。
- SKU依自身工作簿合同兼容有源证据的合法ABA缺失/空流量层，不补F层；异常占位、未知复合状态或冲突回上游核实，不改原数据。
- `品类产品通用词库`、上游独立`二类词`Sheet与F2`二级词`是三个对象；本轮不增加06/10 Sheet或SKU候选人口。独立二类词的额外交付仍待用户明确。
- 获准历史词库复用时保留历史source与当前换卡输出血缘；旧SKU事实不覆盖当前事实。来源Run不同本身不等于污染，未锁定关系或哈希冲突才阻断；不将历史QA/未执行升级为新P1。
- Amazon 关键词项目总工作簿是 SKU 副线程的输入，不是 Listing 可直接使用的搜索词库。
- `SKU可用关键词库` 副线程输出才是可直接用于 Listing 的清洁结果；总控不得恢复上游已剔除的非英文字母/数字、标点或拼写错误词。
- 品类根词与主输入产品类型不一致时，记录定位冲突，例如 `office chair` 与 `gaming chair`；不自动删除，也不静默改定位。
- 品牌词、竞品词、ASIN、促销词和不真实属性不得进入最终埋词映射。

## 可替换性

更换独立关键词 Skill 时，只修改本文件的接口说明和最低兼容列；下游只读取标准化 `06`。公开 Listing 的搜索词来源仅限 `SKU可用关键词库` Sheet。
