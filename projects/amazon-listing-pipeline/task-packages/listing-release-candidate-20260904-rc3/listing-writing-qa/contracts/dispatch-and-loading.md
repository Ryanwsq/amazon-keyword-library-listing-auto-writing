# 任务包加载与交接边界

本文件只规定拆分包的加载和交接，不替代任何业务Skill及其完整合同。

## 加载

1. 主任务和每个副任务各有一个独立包入口。先核对明确下发的角色、包版本、package-manifest.json哈希，再完整读取包内AGENTS.md、Agent.md、LOAD_ORDER.md及所属SKILL.md。
2. 完整读取所属Skill要求的知识和reference。knowledge-base/index.md、rules/index.md及哈希只是导航与校验，不替代正文。按任务阶段选择适用文件，不能跳过已选文件的条件、例外或停止规则。
3. dependencies/及主任务包中非所属Skill仅用于理解输入合同、监督边界和追溯，不授予该任务执行别的模块的权限。跨模块工作仍分发给登记的负责任务。
4. 不从用户全局Skills、旧工作树或另一Run静默补读同名规则。找不到当前锁定依赖、版本不一致或有冲突时停止受影响部分，向主任务报告。
5. 包为带哈希的部署快照。先在原权威文件经授权迭代，再构建新版本；不要直接修改快照使多份规则分叉。历史Run继续原锁定规则，不能因当前包更新而静默升级。

## 接收与执行

- 默认downstream_intake只接收封存输出。重新采集Alexa或重做业务判断需要主任务明确锁定输入、Run_ID、SKU/ASIN、来源路径及SHA-256、运行模式和启动授权。
- `full_pipeline`完成输入与`marketplace`锁定后，主任务立即按总控的固定任务会话登录合同下发八会话矩阵并引导用户准备全部登录。SIF/卖家精灵各自由实际拥有任务按输入表中的非敏感引用使用浏览器已保存凭据或本机密码管理器；六个Amazon拥有任务由用户逐任务手动登录。每个Task/host/dispatch独立回执，八份齐全前不查询、不提问、不导出、不采集联想；登录态不得跨任务推定，密码、验证码、Cookie、令牌和真实任务绑定不进入包或Git。
- 页面进入非锁定站点时，停止受影响模块，记录`marketplace_mismatch`并通知用户介入；不得静默切换或以美国站结果补德国站。
- 只读初始化不是业务启动。未分发真实输入时，不打开业务网页、不处理历史输入、不创建业务Run或输出工作簿。
- 保留当前事实与来源身份；旧类目词库复用只授权词数据，不能带入旧SKU事实或沿用旧SKU筛选结论。若当前交接合同无法明确表达复用关系，回主任务确认接口，不自动改合同。
- 事实未知、未抓取到、身份异常、技术失败、未执行、真实零值各自保留；样本和QA/P1限制原样传递，不升级。
- 各Skill自己的来源、问题次数、重试和停机规则保持独立。不得统一成一条通用网页/重试规则；尤其不能把标签Listing Expression访问权限用于替代Alexa事实。
- 同一任务忙于其他Run时排队，不覆盖当前输入；Amazon-US购物助手仍按所属Skill保持独立上下文。Amazon-DE的Rufus无可靠`New Chat`且刷新后可能保留上下文，按所属Skill使用自含ASIN的固定德语问题并记录`context_independence=not_available`，不因此阻断；面板已显示时不得再次点击开关将其隐藏。送达不确定时先查回执，不盲目重复派发。
- 主任务保留信息校准与实际正文确认两道人机门，副任务不能代用户确认。状态与产物仍按各自Run清单管理。

## 本地与发布

本批是脱敏候选，不含本机来源路径、原聊天、真实任务绑定或历史业务输入输出。发布状态以PUBLICATION.md及候选清单为准；模板与匿名规则说明不提供新SKU事实，也不构成新案例/P1。真实任务映射和装载回执由安装环境单独提供，不进入候选。

外部工具、Spreadsheets运行环境、浏览器登录及权限不随包自动安装。文件齐全或结构测试通过，不等于已登录、业务成功或新增P1验证。
