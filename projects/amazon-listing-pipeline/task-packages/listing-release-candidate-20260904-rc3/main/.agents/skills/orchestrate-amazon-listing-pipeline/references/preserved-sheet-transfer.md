# 四张来源表的保真装配

用户于2026-09-03明确允许“底层文件复制方式原样搬入”，并要求写入Skills。此方式仅用于已验收06中四张源Sheet的无重算复制，不作为任意改写工作簿、绕过SKU筛选或替代正文/展示表工具的许可。

## 顺序与所有权

1. 锁定当前Run、ASIN、06路径/SHA-256及四张源表映射；源为SKU可用关键词库、品类产品通用词库、关键词趋势性分析、关键词竞争性分析。名称不同须显式登记映射，不猜测。
2. 用当前表格Skill的工具生成或更新正文、规则/覆盖和三张优先级展示表；为四张源表创建同名空占位，位置按14Sheet合同，不提前标为可交付。
3. 将工具导出的基础工作簿作为只读target，使用`scripts/copy_preserved_sheets.py`把四张原表及关联部件搬入新输出。必须提供Run_ID、精确源/目标SHA-256、四个明确Sheet名和新的输出/审计路径。
4. 该脚本在ZIP/OOXML层复制：保留原值、类型、空白、公式和缓存；合并并映射共享字符串与样式；原样搬入图表、绘图等闭合依赖；不调用计算器，不重新按源值重建图表。
5. 校验通过后仅只读重载/渲染最终包，不再用表格工具重新导出整个工作簿，以免改写已锁定缓存或关系。确需改正文/展示布局时，回基础工作簿修正，再重新搬表和验收。
6. 原件不覆写。用户明确要求替换既有交付时，先备份旧09/10/manifest，再通过独立校验的新包替换指定文件，登记旧/新哈希及授权，不迁移其他Run或消除样本/QA限制。

## 命令合同

```text
python copy_preserved_sheets.py
  --source <已验收06绝对路径>
  --target <表格工具输出的基础工作簿绝对路径>
  --output <不存在的新输出路径>
  --expected-source-sha256 <锁定06哈希>
  --expected-target-sha256 <基础包哈希>
  --run-id <当前Run_ID>
  --audit-json <不存在的新审计路径>
  --sheet SKU可用关键词库
  --sheet 品类产品通用词库
  --sheet 关键词趋势性分析
  --sheet 关键词竞争性分析
```

上述尖括号是文档占位，不把示例当真实路径执行。使用当前依赖加载器提供的Python，不修改独立SKU关键词Skill。

## 必查项与停止条件

- 逐Sheet值/公式/缓存一致，逆转允许的SST/样式ID映射后整张worksheet结构一致；包括行列尺寸、合并、格式、空白和条件格式。
- 图表/绘图原始部件及系列/缓存保留，所有内部关系能解析；不混入未交付工作表、不产生外链或断链。
- 其他目标Sheet的XML不变；原06与基础target哈希不变；输出ZIP完整、14Sheet顺序一致。
- 当前保守脚本拒绝非空占位、缺表、未知跨表公式、外部数据关系、不同主题、源定义名称、自定义表样式及需另行映射的结构化表。遇到这些情况先补可审计的依赖/映射实现和测试，不静默删对象、转值或改换来源。
- 当前实现成功处理某份06，不等于所有工作簿均已兼容；登记实测覆盖与未支持边界。
- 重写OPC内容类型/关系文件时使用兼容的默认命名空间；ZIP及XML闭合检查通过后仍须实际重载验证，不能只看压缩包可解开。需要额外命名空间映射的markup-compatibility属性当前拒绝，待补显式映射再处理。
- 最终再独立核对源/目标值与公式、606等实际公式数量（按本Run实测，不写死）、图表数/系列数和关键范围视觉。源表固有显示缺陷另记，不为美化擅改“原封不动”的源表。
- 这些是本地装配验证，不等于上游独立QA、P1或Amazon审核通过。
