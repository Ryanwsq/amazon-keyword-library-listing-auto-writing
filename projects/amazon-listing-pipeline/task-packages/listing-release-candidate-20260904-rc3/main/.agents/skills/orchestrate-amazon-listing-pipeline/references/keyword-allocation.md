# 关键词与标签落位规则

## 输入

- 已完整确认的 07 信息校准包，包括标签排序、卖点优劣势、痛点限制、P0、主图/A+初步排布和 ST 去重口径；
- `05_Amazon标签优先级决策.xlsx`；
- `06_SKU可用关键词库.xlsx`；
- 锁定 Ground Truth；
- 可选的 `08_Alexa痛点口语表达.xlsx`。

## 先核验已验收边界，再分配

不重新执行SKU终筛，不更改06保留/剔除结论；发现事实变化交回SKU任务。先核验当前Run与已验收06身份/哈希及事实准入，再按字段采用不同排序，不用一套通用顺序覆盖所有字段：

- Title：06核心大词至中长尾中，有搜索量、带卖点且包含核心品类词根的候选，先按原月搜索量降序，再对照确认卖点优先级选词。
- IH：基本不按搜索量排序；先排除Title已表达卖点（含T0），再补未表达T0、重要卖点/配件和必要使用信息。
- Bullet：先按卖点及用途组合定内容，再补Title/IH未分配的库内搜索词。
- ST：实际正文确认后，按07确认口径处理剩余词。

搜索量不能增加重复次数或覆盖事实冲突；ABA、趋势、竞争性保留参考，不在本轮新增打分算法。词源及标题对照详情见项目listing-title-highlight-writing-rules.md。

## 关键词分组

- K1 核心品类词：产品是什么。
- K2 核心卖点词根：选中主张的结构、功能或材料事实。
- K3 场景/人群/用途长尾词：谁、在哪里、完成什么。
- K4 合规同义词和补充长尾：前台没有自然覆盖但真实相关。
- KX 排除词：品牌、竞品、ASIN、促销、主观最高级、不真实属性、乱码或不可用变体。

## 字段分配

### Title / Item name

保留核心品类身份，按“原搜索量排序→卖点对照→选词”执行，不改为搜索量仅同级参考。合并共有核心词根、记录实际采用片段，有空间补未表达T0。最多75字符，尽量用足必要信息，无颜色，不用set/combo类泛套装填充，不要求自然语言完整句。完整源词量不能转记为根词量或新组合量。

### Item Highlights / 商品亮点

按IH-TITLE-DEDUPE-01先排除标题已表达的卖点（包括T0），优先补未表达T0，再依确认顺序选3–4个重要卖点/配件，并补该类目必要场景/人群/适配信息。默认不按搜索量排序。最多125字符、无颜色，允许逗号/分号短语罗列；预算冲突展示取舍，不静默漏必要项。

在上述内容准入后，按标题知识库IH-COMPONENT-GROUP-01合讲相关部件属性，并按IH-BENEFIT-DEDUPE-01取舍同一收益下的重叠配置。Title、IH、Bullet中的尺寸统一执行FRONT-COPY-DIMENSION-EXPRESSION-01；数字或定性短语只改变事实表达，不产生新搜索量，不放宽06准入或核心词根要求。事实表达与主动埋词分别登记。

### Bullet Points

按软性知识库的五类动态内容块执行：T0（可多条）→T1组合→T2组合→配置背书→售后。v2.2当前至少5条、通常5–6条；自然合讲后五条完整就不补第六条，超过六条须确认环境/条数；无固定字符最低值、目标或上限。每条一个购买理由，可由多个共同用途的配置支撑，自然加入匹配标签。参数/配件背书块允许清单，售后须有事实。

主动埋词步骤：
1. 读取当前06候选，识别Title/IH已分配并实际采用的关键词。
2. 从Bullet主动目标中去除已埋关键词；剩余按原搜索量排序后，结合本条主题与英文自然度选取。不以词流量重排卖点或制造场景。
3. 追溯原关键词、源行、采用片段和真实覆盖；语法变化可记录，不跨无关片段拼凑完整短语命中。
4. 关键词去重粒度尚未由用户统一确认。草案可提出“按源关键词/完整词组去重，共有品类词根允许必要自然复用”作为显式建议，正文讨论时确认；不默认为所有词根禁止重复。词根合并不虚报完整命中，也不当作所有含该词根候选均已埋入。
5. 描述已有卖点或必要品类名不等于再次分配主动埋词；T0可从Title/IH进入Bullet深入讲用途。

已采用P1标签在匹配前台或核心视觉资源中覆盖，不强迫每条描述重复。P2/P3在适合主题的候选中依确认顺序选择，未采用标签不进入正式Listing。主图/A+复现次数单独执行。

### Search Terms

必须在 `copy_checkpoint` 明确确认标题/IH/五点后才生成最终值；文案确认前只做词池计划，不能把草稿当最终前台去重依据。

- 优先放 Title、Item Highlights 和 Bullet 中尚未覆盖的 K3/K4 词。
- 全部小写，单空格分隔，无标点、品牌、ASIN、SKU、促销和主观词。
- 按最终文本 UTF-8 字节数校验；上限只从锁定站点的当前后台/类目规则与证据读取，不从输入工作簿覆盖，也不得跨站点套用249 bytes。
- 按 07 `未决规则` Sheet 中人工锁定的 ST 去重范围执行；不得继续使用未确认的默认口径。

### 图片和 A+

- 用于消费者理解和证明，不把图片或 A+ 当作当前运行的文案/埋词区。
- 场景图表达场景和用途；人群适配图必须有尺寸/结构依据。
- 当前项目只输出位置、卖点、场景、人群、用途和参数等标签式预览，不生成主图/A+短文案、模块标题或 Alt Text。

## 09 工作簿

09 分为计划与实际闭环两次装填：文案确认前实际次数、实际占用和最终 ST 留空并标待确认；确认后逐字基于已锁定正文和最终 ST 计算，不将未执行填成 0。五点预算“硬上限”记项目不设固定上限；若有当次已核验后台限制另列来源。版本与阶段状态写入证据。

### 关键词分配

`关键词｜中文翻译｜分组｜搜索量｜ABA月排名｜产品匹配｜主张匹配｜分配字段｜计划次数｜实际次数｜状态｜理由`

在本Sheet表后或关联证据中保留Title候选原分类/源行、搜索量名次、核心词根、对应卖点等级、采用片段及取舍；Bullet记录Title/IH排除目标和去重粒度状态。不改变06结构，不额外增加09 Sheet。

### 标签落位

`标签｜标签类型｜内容优先级｜目标字段｜目标 Bullet/图片/A+ 模块｜实际表达｜覆盖状态｜证据`

### 字段预算

`字段｜硬上限｜计划占用｜实际占用｜单位｜重复词检查｜状态`

### 排除词与原因

`原始词｜来源｜排除原因｜触发规则｜是否需要人工复核`

## 覆盖验收

- 每个采用的K1/K2词有主要落位；IH不得重复标题卖点；必要品类词复用与Bullet深入展开另记，不误判为重新分配新搜索目标。
- 每个 P1 标签在前台或核心视觉中自然出现。
- P2/P3 的落位与内容资源等级一致。
- 排除词有明确原因，不静默丢弃。
- 字段预算、实际文本和覆盖次数相互一致。
