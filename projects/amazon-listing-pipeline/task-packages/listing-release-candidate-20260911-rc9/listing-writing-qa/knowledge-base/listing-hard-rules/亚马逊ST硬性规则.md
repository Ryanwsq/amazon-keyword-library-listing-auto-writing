# Amazon 后台 Search Terms 硬性规则

> 适用范围：Run锁定站点的 `Search Terms` / `generic_keywords` 字段；下列249 bytes是美国站规则，德国站不得静默套用
> 规则冲突时，以当前站点、商品类型、后台字段、上传模板、Processing Summary 及错误提示中的更严格限制为准。

2026-09-11复核：本文件包括官方禁限项与项目保守提交格式，后者不冒充新的平台处罚政策。选词、去重、取舍和正反例由项目 `knowledge-base/listing-search-terms-writing-rules.md` 拥有。只对新锁定版本生效，旧Run不热切换。

## 1. 字节上限

- Amazon-US后台未显示更严格限制时，整个 `generic_keywords` 属性必须小于 250 bytes，即最多249 bytes。Amazon-DE必须先锁定当前德国站后台或类目规则的可核验上限；未核验时保持待确认，不得用249冒充德国站规则。
- 当前上传模板、处理报告或错误提示要求小于 200 bytes 时，最多 199 bytes。
- 上限按整个字段计算，不是按单词或词组分别计算。
- 必须按最终文本的 UTF-8 字节数校验，不得用字符数代替字节数。
- 超过适用上限时，Amazon 可能忽略整个字段。
- 本项目保守按最终原样文本计数，包含普通空格；不依据历史帖子“不计空格”的说法扩大预算。没有230–245 bytes的强制目标或最低长度，不要求填满。
- 后台能保存、出现多个输入框或某个接口容许更多字符，不证明搜索索引预算更大；按适用属性/模板的总限制处理，不拆框绕过。不能把超限可能忽略ST说成全Listing流量必然清零。

## 2. 格式

- 使用小写字母。
- 单词之间只能使用一个普通空格。
- 不得使用逗号、分号、冒号、连字符或其他标点作为分隔符。
- 不得使用项目符号、Emoji、HTML、JavaScript 或其他特殊格式。
- 不得写完整营销句，不得添加标题、标签或说明文字。
- 不得保留首尾空格或连续多个空格。
- 德语使用正常小写及变音符，不限定ASCII英文；先做Unicode NFC规范化再检查最终文本。ASCII大写和小写均为1 byte，小写要求不是因为大写更占字节。
- ST内部不重复相同词；通常不写无意义虚词、刻意错拼或同意图单复数堆叠。同义称呼/常用缩写/合法拼写变体不是一律禁止，须符合06来源、事实及已锁定去重口径。不得盲删否定/限制词造成误导。

## 3. 真实性与相关性

- 所有词必须与当前商品真实相关。
- 不得填写商品不具备的品类、功能、材质、用途、适用人群或其他误导性信息。
- 不得使用 Search Terms 规避标题、属性或商品详情页的真实性及合规要求。

## 4. 禁止内容

- 自有品牌、竞争品牌、其他公司、产品线或商标名称，以及故意拆写、错拼或变形的品牌名称。
- 自有或竞争对手的 ASIN，以及拆分、变形或规避识别的 ASIN。
- 内部 SKU、内部型号记录或商品管理备注。
- `new`、`sale`、`on sale now`、`limited time`、`available now` 等临时性、促销性、库存或时效陈述。
- `best`、`cheapest`、`amazing`、`top rated`、`number one`、`perfect` 等主观、排名、价格优势、最高级、比较性或无法证明的宣传词。
- 与违法活动、仇恨、暴力、歧视、辱骂、冒犯或其他违规内容有关的词。

## 5. 提交前硬性检查

- UTF-8 字节数未超过当前适用上限。
- 格式仅含合规的小写词和单个空格。
- 所有词均与当前商品真实相关。
- 不含品牌、ASIN、临时性陈述、主观宣传词或其他禁止内容。
- 最终ST基于当前已验收06、已确认正文和07去重范围；前台有修改时重算，不把前台草稿、跨字段拼接或词元覆盖当完整短语命中。
- 机械通过不等于事实/合规审核完成，更不证明被Amazon收录、排名提升或P1。

## 6. 官方来源及核验边界

复核于2026-09-11：

- [Amazon SEO，第5节](https://sell.amazon.com/blog/amazon-seo)：后台补充、相关性、小写及空格；不用其其他字段建议修改项目Title/Bullet规则。
- [Amazon官方搜索词公告](https://sellercentral.amazon.com/seller-forums/discussions/t/62e0e515a6e991d171d3ccee7be36304)：同义词/缩写/替代名称；自有及其他品牌、ASIN、临时陈述、主观夸大与冒犯词禁用。
- [Amazon官方提示](https://sellercentral.amazon.com/seller-forums/discussions/t/923d53dc-a182-4475-a164-6b2500dbaf2d)：不重复、无须虚词/标点、合法拼写变体与常见错拼分开、避免其他属性已有信息。
- [Cooper_Amazon官方答复](https://sellercentral.amazon.com/seller-forums/discussions/t/8e1ad5d2-5d5f-4086-bda3-735505e23bb1)：249 Bytes；[Amazon教育材料第3页](https://m.media-amazon.com/images/G/01/AGS/SEA/RSEA/AGS_RNL_2020/RNL_3.pdf)写明小于250 bytes。公开材料存在历史“字符/字节”表述差异，仍按当前具体后台约束核验，不取最宽说法。
