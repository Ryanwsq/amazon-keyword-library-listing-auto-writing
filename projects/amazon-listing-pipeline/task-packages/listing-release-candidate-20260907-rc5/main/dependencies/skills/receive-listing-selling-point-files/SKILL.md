# 卖点配置文件接收

## 当前职责

这是既有接收整理任务的文件化入口，不新增业务裁决权。默认只接收、读取、核对和登记上游结论。完整读取[接收合同](references/intake-contract.md)。

## 输入与输出

输入是主任务明确锁定Run_ID、产品身份、版本、精确路径及SHA-256的卖点配置包。输出为接收回执、字段/证据对应关系、冲突与待确认事项；不自行约定新的业务Excel结构。

## 执行

1. 核对下发角色与当前任务包版本；没有业务输入时只完成只读初始化。
2. 核对文件身份、哈希、可读性、所需字段及上游状态；源文件保持只读。
3. 保留全部卖点、配置、优势/劣势、中性与未知、原排序、事实来源、Alexa识别状态及限制。
4. 原样呈现上游排序及待确认事项。只有主任务另行明确归一/合并规则、稳定ID、验收标准和输出位置后，才进行获准整理；保留全部原始映射，不自造评分。
5. 回报已核对范围与缺口；没有证据不得补值。缺失、冲突或接口未锁定时返回partial/blocked并列明原因。

## 禁止与质量门

不启动Alexa采集，不把竞品未提及当作没有，不用模型常识补事实，不改写源文件或优劣势，不生成标题/IH/Bullet、图片/A+布局、QA或评论，不替主任务做人机确认。接收通过仅表示核对成功，不表示上游独立QA或业务P1通过。
