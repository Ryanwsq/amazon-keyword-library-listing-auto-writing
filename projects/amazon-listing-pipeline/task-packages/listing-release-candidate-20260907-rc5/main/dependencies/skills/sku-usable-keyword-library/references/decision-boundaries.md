# SKU产品事实匹配边界

## 1. 上下游边界

上游`品类相关`在本项目接口中表示品类相关性与搜索意图已经完成筛选。本Skill直接继承该结论，不重新判断关键词是否属于目标品类、是否为配件/其他商品或用户搜索意图是否适合。

本Skill只核对关键词中明确表达的材质、结构、功能、规格、人群、场景、用途或其他SKU事实限制是否被当前SKU事实卡支持。

不得反向修改上游`最终去向、品类关系、通用词库资格、动态语义标签、竞争性强度`或其他结论。

## 2. 证据优先级

SKU事实只能来自锁定`SKU事实卡`中的确认值和状态/来源。

- `锁定事实、用户锁定事实、用户确认、运行锁、锁定事实压缩`等已确认状态可作为证据。
- 空白、未抓取到、未知、待确认、冲突、身份异常或无法唯一对应当前SKU的内容不能作为通过证据。
- 上游关键词标签、中文翻译、竞品信息、流量、排名、搜索量和模型常识都不能补足SKU事实。
- 中文翻译只辅助理解；英文原关键词是判断主文本。翻译与原词冲突时，以原词为准并记录问题。

## 3. SKU事实匹配

先识别完整关键词明确表达的约束，再逐项与事实卡核对。

### 3.1 不复判上游对象与意图

- 不重新识别中心购买对象，不重新执行配件、零件、其他商品或信息意图分流。
- 不因词面宽泛、语言变体或模型对搜索意图的理解而筛除上游`品类相关`行。
- 只识别完整关键词是否增加了需要与SKU事实卡核对的明确产品事实限制。

### 3.2 明确属性和配置

关键词出现以下明确限制时，必须有事实卡直接支持：

- 品牌、型号、颜色、材质；
- 尺寸、重量、承重、数量、档位、角度、范围；
- 结构、部件、扶手、靠背、底座、脚轮；
- 功能、电子配置、按摩、加热、灯光、音响；
- 随售配件、组合内容、安装形态；
- 适用人群、兼容对象、使用条件；
- `with/without/no`等肯定或否定配置。

精确支持则该约束通过；明确冲突则不通过；事实卡未覆盖则待确认。不得把“未提及”解释为具备，也不得把相近规格自动视为相同。

#### 项目级用户锁定材质等价规则

在本Listing信息决策项目中，用户已明确锁定：SKU事实卡中的`人造皮`可以承接没有进一步材质等级限定的泛化英文`leather`。

- `leather gaming chair`、`gaming chair leather`等只表达泛化`leather`的词，不得仅因事实卡写作`人造皮`而判定不匹配。
- 该等价只覆盖没有进一步等级、真皮承诺或其他具体材质限定的`leather`。`genuine leather`、`real leather`、`top grain leather`、`full grain leather`、`cowhide`等仍需事实卡直接支持；不能由`人造皮`推出。
- `suede`、`velvet`、`fabric`、`cloth`、`mesh`、`plush`等不是本规则中的`leather`等价词，仍按原文限定与事实卡逐项核对。
- 关键词同时包含颜色、承重、人群、结构或其他冲突限定时，即使泛化`leather`可承接，仍须依据其他限定独立判断。

这是当前项目的用户锁定规则，不得外推为其他项目、其他SKU或通用品类词库的普遍材质定义。

### 3.3 宽泛词和无额外约束词

关键词未增加任何需要核对的SKU事实限定时，SKU事实匹配直接通过。不得因为关键词宽泛、语言变体或意图歧义而自动失败或待确认。

### 3.4 场景、人群和用途

场景、人群或用途是明确搜索限制时，必须被事实卡直接支持，或者能由事实卡中的对象与用途陈述直接推出且不需要新增产品事实。

仅因行业常见、竞品常见或“通常可以使用”不能通过。儿童、医疗、专业用途、安全承诺或其他高风险限制必须有明确证据。

## 4. 单维度最终结论

| SKU事实匹配 | SKU最终结论 |
|---|---|
| `通过` | `SKU可用` |
| `不通过` | `SKU不可用` |
| `待确认` | `待确认` |

不得新增搜索意图、品类关系、流量、ABA、竞争或趋势维度影响本模块最终结论。

## 5. 动态标签使用边界

上游动态语义列由关键词文字产生，可用于快速识别关键词表达了哪些限定，但不能证明SKU具备该限定。

- 标签存在：仍需回到英文完整关键词和事实卡核对。
- 标签缺失：不能证明关键词没有该语义。
- `长尾主分组标签`只服务F5分组，不是全部关键词的语义分类标签。
- 动态标签不得新增、纠正、重排或根据SKU事实改写。

## 6. 批量一致性

同一规则必须应用于全部候选。不得只修改被人工点名的词，也不得把共享模板理由直接外推为整组结论。

至少反向抽查：

- 无额外SKU事实限定的宽泛词；
- 颜色、材质、尺寸、承重和结构词；
- `with/without/no`配置词；
- 人群、场景和用途词；
- 其他语言及词形变体中的明确SKU事实限定；
- 事实卡缺失导致的待确认词。
