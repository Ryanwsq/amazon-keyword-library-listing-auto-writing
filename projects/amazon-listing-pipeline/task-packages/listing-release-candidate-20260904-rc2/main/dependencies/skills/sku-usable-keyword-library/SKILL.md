# SKU Usable Keyword Library

## 目标

把上游已判为`品类相关`的关键词仅按当前单个SKU事实进一步收敛。上游的品类关系与搜索意图结论直接继承，本模块不复判；`SKU事实匹配=通过`且同时通过Sheet1字符规则和拼写规则的关键词才能进入最终关键词Sheet。第一张Sheet作为可直接用于Listing的关键词来源，不允许标点、符号、数字或异常空白混入。

## 必读合同

正式运行前读取：

- [判定边界](references/decision-boundaries.md)：逐行判断SKU产品事实时使用。
- [工作簿合同](references/workbook-contract.md)：锁定输入、五字段映射、四张继承Sheet原样复制和质量门时使用。
- [参考来源与继承边界](references/reference-provenance.md)：发生上游规则冲突或需要解释规则来源时使用。

## 输入

一份锁定的Amazon关键词项目最终工作簿，至少包含：

- `最终关键词决策总表`；
- 唯一一张`SKU事实卡`；
- 可验证的文件名、SHA-256和Run身份。

当前一次运行只处理事实卡中的一个SKU。不得把其他SKU、竞品、网页、模型常识或Listing文案作为事实补全来源。

## 候选人口

只读取`最终关键词决策总表`中`最终去向`去除首尾空格后精确等于`品类相关`的行。该字段表示上游已经完成品类相关性与搜索意图筛选，本模块不得重新判断关键词是否属于目标品类、是否为配件/其他商品或搜索意图是否适合。

- 不再执行搜索量、ABA、流量层、竞争性、趋势、词频或`通用词库资格`筛选。
- 不重新判断上游三去向，也不改写任何上游字段。
- 其他去向、空白或错误值行不进入本模块候选人口。

## 执行流程

1. 锁定源文件哈希、Sheet名称、表头行、候选人口、稳定`Keyword_ID`和唯一SKU事实卡。源文件全程只读。
2. 识别固定字段、`流量层`以及四张必需继承Sheet：`品类产品通用词库`、`词频统计`、`关键词竞争性分析`、`关键词趋势性分析`。`流量层`按合同映射F1–F5；仅合同第3节有主键级来源证据的合法ABA缺失组合允许分类空白，不补层、不筛掉合法缺失候选。动态语义标签可辅助理解，但不进入最终第一列，也不作为SKU事实证据。
3. 对每个候选完整读取英文关键词、中文翻译、动态标签和SKU事实卡，只提取关键词明确表达的SKU属性、配置、规格、人群、场景或用途限制；不得复判品类或搜索意图。执行项目级用户锁定的材质等价规则时，以[判定边界](references/decision-boundaries.md)记录的精确适用范围为准。
4. 作出唯一判断`SKU事实匹配`，允许值只有`通过、不通过、待确认`，并记录事实卡字段或逐行理由。
5. `SKU事实匹配=通过`时写`SKU可用`；`不通过`时写`SKU不可用`；`待确认`时写`待确认`。
6. 对原始`英文关键词`执行Sheet1字符规则：原值必须完整匹配`^[A-Za-z]+(?: [A-Za-z]+)*$`，即只允许ASCII英文字母，单词之间只允许一个ASCII空格。只要含数字、非ASCII字母、任何中英文标点、引号、连字符、加号、逗号、句点、斜杠、其他符号/控制字符，或存在首尾空格、连续空格、Tab/换行，整行标记`字符规则排除`。不得删除字符、合并空格、改写或标准化后保留。
7. 对原始`英文关键词`执行Sheet1拼写规则：仅当词在完整短语语境中存在可明确还原的错拼、错字或字母错位时，标记`拼写规则排除`。不得因单复数、正常词形、非英语词、品牌/型号、行业缩写、地区拼法或仅因通用词典未收录而排除。正确词无法唯一确定时写`拼写待确认`，不进入Sheet1，不自行纠错后保留。
8. 将全部候选的主键、源行、事实匹配结论、依据、最终结论、字符规则结果、拼写规则结果和Sheet1输出资格写入过程决策账本；`SKU可用关键词库`只输出`SKU最终结论=SKU可用`且字符规则、拼写规则均通过的行。
9. 按源表行序生成五字段关键词Sheet，不按流量或竞争性重新排序；再以同一锁定输入工作簿为底稿原样保留`品类产品通用词库`、`词频统计`、`关键词竞争性分析`、`关键词趋势性分析`。
10. 完成主键、人口、字符与拼写排除、字段、五Sheet结构、复制一致性、公式、绘图关系和视觉检查。

## 最终输出

用户工作簿必须依次包含五张Sheet：

1. `SKU可用关键词库`
2. `品类产品通用词库`
3. `词频统计`
4. `关键词竞争性分析`
5. `关键词趋势性分析`

第一张Sheet只含`关键词分类、关键词、中文翻译、月搜索量、ABA月排名`五列。字段值与F1–F5分类映射按[工作簿合同](references/workbook-contract.md)机械生成，并排除命中字符规则或拼写规则的行。不得加入`竞争性强度、Keyword_ID`、判断结论、理由、LT、广告或Listing字段；审计信息只留在过程决策账本。后四张Sheet必须来自同一锁定输入，并以原工作簿部件直接保留方式保持源Sheet名称、单元格值、公式、样式、合并、列宽行高、冻结、筛选、图表和其他可见结构；不重算、不重建、不删改、不重排其内容。

## 停止与人工升级

以下情况停止，不自行修复或猜测：

- 指定Sheet或必需字段缺失、重名或无法唯一定位；
- SKU事实卡缺失、存在多个SKU且未指定，或事实互相冲突；
- 文件哈希、候选人口或`Keyword_ID`映射在运行中变化；
- `流量层`列缺失、值不在F1–F5且不满足工作簿合同第3节的合法空白例外，或四个必需继承Sheet缺失/重名；
- 缺少一条会系统性改变整类关键词结论的规则。

单行事实不足或语义歧义不停止整批，写`待确认`。只有系统性规则缺口才返回`NEED_RULE_CLARIFICATION`及受影响人口，不得编写替代规则。

## 质量门

- `SKU可用 + SKU不可用 + 待确认 = 候选人口`，每个候选`Keyword_ID`恰好一次。
- 最终工作簿第一张Sheet行数等于`SKU可用且字符规则、拼写规则均通过`数量，且每行能回查到过程账本和源行。
- 源文件哈希不变，源Sheet、原行、原值、公式和格式均未改写。
- 第一张Sheet五个输出字段名称和顺序精确一致；数值和空值不伪造、不以0代替缺失。
- `关键词分类`只能由源`流量层`机械映射：F1→核心大词、F2→二级词、F3→中流量词、F4→中长尾词、F5→长尾词；合同第3节合法ABA缺失例外留空，源状态/原值/证据留过程账本，不增加最终列。
- 字符规则人口闭环：每个候选必须记录`通过/字符规则排除`；Sheet1的`关键词`列每个原值都必须完整匹配`^[A-Za-z]+(?: [A-Za-z]+)*$`，数字、非ASCII字母、标点、符号、控制字符和异常空白零混入。
- 拼写规则人口闭环：每个候选必须记录`通过/拼写规则排除/拼写待确认`；明确错拼或拼写待确认行零混入Sheet1，且不得纠错后保留。
- 最终工作簿恰好五张Sheet且顺序正确；后四张继承Sheet与锁定输入逐单元格、公式和可见结构一致，不进行任何重算或改写。
- 最终工作簿无多余Sheet、字段、重复关键词映射、公式错误、断裂绘图关系或不可读区域，并完成五张Sheet渲染目视复核。
