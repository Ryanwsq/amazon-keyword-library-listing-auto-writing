# 阶段：商品信息审计与参数优势

## 负责范围

调用 `$audit-alexa-shopping-product-info`，验证 Alexa 对本品 Ground Truth 的识别，并抓取五类对标竞品的相同字段；接收其独立输出的参数优势和原始卖点排序。

## 输入

- `locked-input/00_锁定输入.xlsx`
- Sheet：`新品基础信息`、`新品基础配置`、`竞品对标ASIN`

## 执行

1. 将阶段置为 `running`。
2. 完整读取并执行依赖 Skill 及其规范性 reference。
3. 不把 `市场竞品ASIN池` 加入该 Skill 的五类竞品矩阵，除非用户也在 `竞品对标ASIN` 中明确选中。
4. 生成依赖 Skill 固定的审计工作簿和独立优势/卖点排序工作簿。
5. 复制为：
   - `02_Alexa商品信息审计.xlsx`
   - `03_本品优势与卖点排序.xlsx`
6. 登记原始证据目录与两个输出路径，完成阶段。

## 给决策层的数据

- Ground Truth 与 Alexa 的逐字段状态和冲突；
- 固定方向表允许的客观参数优势；
- 按依赖 Skill 三层排序键得到的原始卖点顺序；
- 五类对标竞品的 Alexa 标准化事实。

## 禁止

- 不把 Alexa 未识别自动解释为产品没有。
- 不把竞品未提及解释为本品独有。
- 不用本阶段卖点排名直接替代最终核心价值主张。
- 不用市场池样本数修饰五类参数对标结论。
