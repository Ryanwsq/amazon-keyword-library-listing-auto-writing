# Amazon Listing 硬性规则知识库

## 定位

本目录收录用户提供并经项目明确修订的 Amazon Listing 硬性规则，作为最终装配与提交前校验的边界知识。

这些文件定义“不得违反什么”和“必须满足什么”，不定义具体写法、语气、文风或说服结构。

## 生效阶段

| 知识文件 | 约束对象 | 生效阶段 |
|---|---|---|
| `亚马逊标题硬性规则.md` | Item name、Item Highlights | 最终 Listing 装配与校验 |
| `亚马逊五点描述硬性规则.md` | Bullet Points／五点描述 | 最终 Listing 装配与校验 |
| `亚马逊ST硬性规则.md` | Search Terms／generic_keywords | 最终 Listing 装配与字节校验 |
| `亚马逊图片硬性规则.md` | 主图与副图 | 图片位置预览、需求边界与提交前校验 |
| `亚马逊A+硬性规则.md` | Premium A+ | A+ 位置预览、内容边界与提交前校验 |

## 使用边界

- 不参与 SKU 可用关键词的事实匹配或搜索意图匹配。
- 不参与人群、用途、场景、痛点、卖点或配置优劣势的事实生成。
- 不得根据规则文件补造产品事实、认证、参数、功能或适用人群。
- 最终装配只能使用已经通过上游决策并完成信息校准的内容。
- 规则校验失败时，应回报具体字段、原文位置和违反的规则，不得静默改写事实。
- `marketplace`必须在Run初始化前锁定；Amazon-US与Amazon-DE的后台限制、语言和计量表达不得互相套用。
- 如站点、类目、Seller Central 后台或当前官方规则存在更严格或更新要求，以更严格且当前有效的要求为准；未完成德国站规则核验时保留待确认，不以美国站默认值补齐。
