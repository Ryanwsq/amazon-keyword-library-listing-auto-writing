# Amazon Listing 图片硬性规则

> 站点：使用Run锁定marketplace；美国站专属条款不得直接套用德国站
> 不包含：A+、品牌旗舰店和广告素材规则  
> 规则冲突时，以当前站点、商品类型、类目 Style Guide、Seller Central 后台及 Image Manager 的更严格要求为准。

## 1. 图片类型与数量

- 每个商品详情页至少必须有 1 张合规主图。
- 第一张图片必须为 MAIN image，并作为搜索结果主图。
- 第一张图片可以选择白底首图或场景首图；两种方案均可作为当前项目的第一张上传图片。
- 一套 Listing 最多 9 张商品图片。
- 家具、办公椅、电竞椅等 hardlines 商品除主图外，至少还必须包含 1 张真实使用场景图和 1 张尺寸/适配图。

## 2. 文件技术要求

- 图片最长边必须为 500–10,000 px；当前类目或后台有更严格限制时从其规定。
- 文件格式仅限 JPEG、TIFF、PNG 或非动画 GIF。
- 色彩模式必须为 RGB 或 CMYK；当前后台要求特定模式时从其规定。
- 图片不得模糊、像素化、锯齿、拉伸、裁切错误或存在明显生成错误。
- 选择白底首图时，背景必须为纯白色 RGB `255, 255, 255` / `#FFFFFF`，商品应约占画面 85%，并完整展示，不得裁掉商品部分。
- 选择场景首图时，可以展示真实、合理的使用环境、人物和不随售道具，但商品必须是清晰可辨的核心主体，且不得误导顾客理解实际随售内容。

## 3. 主图要求

### 必须

- 只展示当前子 ASIN 实际销售的商品及实际随售内容。
- 商品颜色、结构、尺寸版本、配置、配件和数量必须准确。
- 商品必须清晰、准确地展示当前子ASIN；白底方案应完整展示且只出现一次，场景方案不得因遮挡、透视或比例处理造成商品结构和实际大小误解。

### 禁止

- 标题、卖点文字、尺寸、参数、箭头、图标、放大圈、局部特写或内嵌小图。
- 额外叠加的品牌 Logo、水印、边框、色块、角标、促销贴或徽章。
- 拼图、多个角度或同一商品重复出现。
- 白底首图中禁止场景、渐变、彩色背景、地面、房间、人物或不随售道具；场景首图不受本条限制，但仍须满足真实性、随售内容区分和安全使用要求。
- 不随售的赠品、配件、错误数量、其他型号配件或不存在的部件。
- 普通运输外箱或包装袋；当前类目允许且包装本身属于商品必要展示的情形除外。
- Amazon Logo、`Amazon's Choice`、`Best Seller` 等平台标识或徽章。

## 4. 副图共同要求

- 商品颜色、结构、配件、数量和比例必须与当前子 ASIN 一致。
- 画面、文字、尺寸、参数、认证、效果和比较必须真实、准确且有证据支持。
- 场景道具必须与实际随售内容清楚区分，不得使顾客误认为道具随商品附赠。
- 商品主体、文字和关键标注在移动端必须可辨认。
- 不得展示不安全、说明书禁止或产品结构无法支持的使用方式。
- 不得通过缩放、拉伸、透视或不真实参照夸大或缩小商品。

## 5. 尺寸、结构、功能与安装信息

- 尺寸数值、测量箭头和起止位置必须一一对应。
- 尺寸及重量单位必须符合Run锁定站点和类目要求；英制与公制换算必须准确。
- 可调范围必须同时写明最小值和最大值。
- 不得把包装尺寸写成商品尺寸，不得从渲染图反推或猜测尺寸。
- 结构、材料、层数、连接关系和部件数量必须来自 BOM、工程图、说明书或其他已确认资料。
- AI 或 3D 生成内容不得自行补全商品内部结构。
- 功能状态、角度、档位、锁定方式和操作路径必须真实；不得展示商品无法同时达到的组合状态。
- 安装步骤必须与说明书一致，不得省略安全关键动作或虚构安装时间。
- 认证和测试只能用于其真实适用的商品、部件、条件和范围。

## 6. 随售内容与对比内容

- 随售内容图只能展示包装内实际包含的商品、部件、工具、说明书和配件，并准确标明数量。
- 不得暗示赠品，不得展示错误数量、不随售道具或其他型号配件。
- 对比内容必须采用一致的条件、单位、定义和数据口径。
- 不得出现竞品品牌、Logo、ASIN、竞品商品图片或未经授权的竞品素材。
- 不得虚构、丑化或夸大竞品缺陷，不得使用无法证明的比较结论。

## 7. 全套图片禁止内容

- Amazon Logo、Amazon 商标、仿制官方标识或平台徽章。
- 与当前 ASIN/子 ASIN 不一致的商品、颜色、结构、尺寸、数量或配件。
- 虚假、无法证明或超出产品事实的功能、效果、参数、排名、比较和认证。
- 价格、折扣、Coupon、促销码、限时优惠、配送承诺或到货日期。
- 伪造星级、评论截图、买家头像或推荐语。
- 电话、邮箱、网址、二维码、社交账号或其他站外引流。
- 竞品商标、Logo、ASIN、商品图片或未经授权的认证标识。
- 未经证据及合规确认的医疗、健康、安全、环保、抗菌或性能承诺。
- 盗用的图片、字体、图标、模特或其他版权素材。
- 裸露、性暗示、违法、仇恨、歧视、暴力或危险内容。
- 误导用户理解实际随售内容的道具、配件、比例或场景。

## 8. 提交前硬性检查

- 主图位于第 1 张，并已明确采用白底首图或场景首图方案；白底方案符合纯白背景、商品占比和完整展示要求，场景方案符合商品主体清晰、真实场景、随售内容区分及禁用元素要求。
- 图片数量、尺寸、格式、色彩模式和清晰度符合当前后台及类目要求。
- hardlines 商品已包含场景图和尺寸/适配图。
- 所有商品事实、参数、配件、数量、认证和功能状态均有依据并与当前子 ASIN 一致。
- 不含本规则列出的任何禁止内容。
