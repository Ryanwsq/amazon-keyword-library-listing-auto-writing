# 阶段：痛点频率与口语表达

## 痛点频率（人工确认前）

调用 `$alexa-painpoint-frequency`。

### ASIN 来源

优先读取 `市场竞品ASIN池` 中启用且采样用途包含 `痛点频率` 的 ASIN；无专用 Sheet 时回退到五类对标竞品去重集合并标记样本风险。

### 输出

保存固定两 Sheet 工作簿为 `04_竞品Alexa痛点频率统计.xlsx`。

### 决策使用

- 有效 ASIN 数达到正式门槛时，频率可作为问题重要性证据。
- 未达到门槛时，只能作为具体风险/个案清单，不参与“高频痛点”排序。
- 痛点必须与本品已确认结构形成可证明的解决关系，才可支持核心主张。
- 不得用竞品痛点反向推断本品一定没有该问题。

## 痛点口语表达（人工确认后，可选）

仅当已确认主张明确解决 `04` 中的某个标准化痛点时调用 `$alexa-painpoint-phrasing`；该条件由流程合同固定，不接受输入工作簿切换。

### 输入

完整的 `04_竞品Alexa痛点频率统计.xlsx`。依赖 Skill 会根据其固定合同筛选有效 `标准化痛点 + ASIN` 对；总控不得制作不兼容的精简替代表。

### 输出

保存为 `08_Alexa痛点口语表达.xlsx`。

### 使用边界

- 输出是 Alexa 归纳表达，不是消费者原话。
- 只能帮助理解自然问法、图片/A+问题表达或 Q&A 方向。
- 不直接复制为评论引语，不冒充消费者频率，不自动生成 Listing Q&A 答案。

若确认主张不依赖痛点，将 `painpoint_phrasing` 标记 `skipped`。
