# Amazon Bullet Points（五点描述）硬性规则

> 默认适用范围：Amazon 美国站  
> 类目、商品类型、站点或后台字段存在更严格要求时，以当前 Seller Central 提示及类目规则为准。

## 1. 数量与字符数

- 用户于2026-09-03明确本项目至少填写5条Bullet Points，替代原项目“至少3条”口径。
- 生效修订BULLET-COVERAGE-COUNT-01：通常5–6条。自然合讲关联卖点并完整覆盖必要信息后，五条足够就不补第六条；六条只用于确需独立展开的信息，不拆卖点、重复内容或虚构承诺凑数，也不为压缩条数遗漏重要信息。五或六条均按实际正文确认，不额外要求五条例外审批。
- 若确需超过六条，须先核对目标环境并取得真实条数确认；不得由六条实测推断任意条数可上传。
- 最大条数以已知目标后台限制为准；历史Run保留原合同。
- 用户于2026-09-03取消本项目五点固定字符目标与上/下限，不再使用旧255/500限额或长度例外；仍报告实际字符数。
- 当前Seller Central/类目模板真实强制限制单独记录并遵守；未知写后台限制待核验，不能把取消项目限制当成取消平台限制。

## 2. 基础格式

- 每条以大写字母开头。
- 允许同一购买理由下多句自然展开；不再强制句子片段或禁止多句。长度由信息价值决定，不堆重复空话。
- 末尾不得使用句号或其他结束标点。
- 使用简短描述性标题头，并在标题头后使用冒号 `:`。
- 内部按语义使用句号或分号 `;` 分隔，不强制只用分号；末尾不使用结束标点的项目格式保持不变。
- 不得在字段开头手动添加 `•`、`●`、`✓` 等项目符号。

## 3. 数字与单位

- 英文数字 one 至 nine 应使用英文单词拼写；名称、型号和测量值除外。
- 数字与计量单位之间必须保留一个空格。
- 数值、单位和规格必须与商品事实及其他 Listing 字段一致。

## 4. 禁止符号与占位内容

- 不得使用商标、版权、货币、装饰性符号或 Emoji，包括但不限于 `™`、`®`、`€`、`…`、`†`、`‡`、`¢`、`£`、`¥`、`©`、`±`、`~`、`☺`、`☹`、`✓`、`❌`。
- 不得填写 ASIN。
- 不得填写 `not applicable`、`NA`、`n/a`、`N/A`、`not eligible`、`yet to decide`、`to be decided`、`TBD`、`copy pending` 或其他待补充、待确认、内部流转用语。

## 5. 禁止声明与交易信息

- 未完成合规确认及证明审核前，不得使用 `eco-friendly`、`environmentally friendly`、`ecologically friendly`、`anti-microbial`、`anti-bacterial`、`made from bamboo`、`contains bamboo`、`made from soy`、`contains soy` 等受限声明。
- 不得写退款、退货、满意度保证、无条件保证、无风险购买或 money-back guarantee 等内容。
- 不得写公司或卖家介绍、网站、外部链接、电话、邮箱、社交账号或其他联系方式。
- 不得写价格、折扣、优惠券、促销活动、库存、商品成色、可售状态、配送时效、免运费或其他交易/配送信息。
- 不得引导买家离开 Amazon 或联系卖家。
- 末条允许说明已确认且符合目标后台要求的真实保修/支持政策，不视为无条件保证；期限、范围、在线时段、回复时效分别有依据。24/7支持不等于24小时内回复，不虚构任一承诺。

## 6. 真实性与一致性

- 每条须有独立购买理由，不重复同一信息或主动堆砌关键词；同一配置再次出现须提供不同用途/机制/选购信息。配置背书条可集中如实罗列参数及配件。
- 商品规格、材质、数量、兼容性、功能、认证及变体信息必须真实、准确、可验证。
- 父子体共用信息必须一致；颜色、尺寸、数量等子体差异必须与当前子体对应。
- 不得与 Item name、Item Highlights、商品属性、图片、描述或 A+ 内容产生事实冲突。
- 认证和测试只能用于其真实适用的商品、部件、条件和范围。
- 不得使用竞争对手品牌、竞争对手 ASIN、无法证明的比较、排名、最高级、绝对化或功效表述。

## 7. 提交前硬性检查

- 条数符合当前Run要求；字符数已报告，已知后台强制限制已满足，未知限制未假装通过。
- 格式、首字母、标题头、标点、数字和单位符合本规则。
- 不含禁用符号、占位内容、交易信息、站外信息或受限声明。
- 所有商品信息真实、可验证，并与当前子 ASIN 及其他 Listing 字段一致。
