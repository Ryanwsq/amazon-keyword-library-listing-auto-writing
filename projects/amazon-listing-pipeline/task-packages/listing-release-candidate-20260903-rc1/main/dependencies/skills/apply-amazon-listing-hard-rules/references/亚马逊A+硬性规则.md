# Amazon Premium A+ 内容硬性规则

> 默认站点：Amazon US  
> 适用范围：当前商品的产品级 Premium A+ 内容  
> 规则冲突时，以当前站点、类目、Seller Central 后台字段、验证提示及 Amazon 最新官方规则为准。

## 1. 模块与数量

- 每个 ASIN 最多使用 7 个 Premium A+ 模块。
- 最终模块名称、可用模块、图片框数量、图片尺寸、字符上限及移动端素材要求，必须以当前 Seller Central 后台显示为准。
- 不得输出或上传超过后台数量上限的模块、图片或文字。
- 不得将 Brand Story、品牌旗舰店内容混入产品级 A+。

## 2. 图片技术要求

- 文件格式仅限 `.jpg`、`.bmp` 或 `.png`。
- 图片必须使用 RGB 色彩空间，不得使用 CMYK。
- 单张图片必须小于 2 MB。
- 分辨率不得低于 72 dpi。
- 不得使用 GIF 或其他动画图片。
- 图片必须清晰，不得模糊、像素化、拉伸、带水印或存在明显生成错误。
- 图片必须符合对应模块上传框的尺寸、比例及桌面端/移动端要求；后台未确认前不得自行假定尺寸。
- 必须拥有图片、Logo、字体、人物肖像及文案的使用权。

## 3. Alt Text

- 每张 A+ 图片必须填写与画面内容一致的 Alt Text。
- Alt Text 必须客观描述图片中实际可见的商品、部件、功能、结构或场景，并与当前 ASIN/变体一致。
- 不得堆砌关键词，不得填写与图片无关的词、竞品品牌、ASIN、促销语或购买引导。
- 不得为不同图片重复填写相同 Alt Text。

## 4. 全部模块共同禁止内容

以下禁令适用于模块文字、图片内嵌文字、图标、徽章、表格、轮播、热点、Q&A 和 Alt Text：

- 价格、折扣、Coupon、促销码、限时优惠、赠送、免费配送或其他促销信息。
- `Buy Now`、`Add to Cart`、`Get Yours Now` 等购买引导。
- 会过期的日期、库存、时效或季节性陈述。
- 保修、保证、退款、退货、换货、维修、满意度保证或售后承诺。
- 配送时效、物流方式或发货承诺。
- 电话、邮箱、地址、社交账号、二维码、外部 URL、超链接或其他站外引流信息。
- 卖家、经销商、分销商或授权渠道信息。
- Amazon Logo、仿制 Amazon 页面元素、Amazon 按钮、`Amazon's Choice`、`Best Seller` 等平台徽章。
- 竞争品牌、竞争 ASIN、可识别的竞争商品、竞品 Logo、竞品图片、竞品包装或贬低竞品的内容。
- Amazon 评论截图、星级、评分数量、买家头像、普通顾客引语或伪装成顾客评价的内容。
- 无法证实的排名、最高级、绝对化、比较性或满意度声称。
- 无法证实或缺少适用范围的认证、测试、奖项、媒体背书、健康、安全、性能、耐用、抗菌或功效声称。
- 治疗、治愈、缓解或预防人类或动物疾病的声称。
- 未经合规确认的环保、可降解、可堆肥、可回收或生态声称及对应图标。
- HTML 标签、关键词堆砌、明显拼写/语法错误、大段全大写、重复感叹号或过度特殊符号。
- 未经授权的商标、Logo、字体、人物肖像、图片或其他版权内容。
- 裸露、仇恨、暴力、违法、危险、歧视或误导性内容。

## 5. 事实一致性

- 所有文字、图片、参数、数量、颜色、尺寸、款式、结构、功能、兼容性、配件、认证和测试信息必须真实、可验证，并与当前子 ASIN 一致。
- A+ 必须与标题、Item Highlights、Bullet Points、后台属性、包装清单、说明书及 Listing 图片保持一致。
- 同一 A+ 应用于多个 ASIN 时，其中全部内容必须对每个 ASIN 成立；否则必须拆分内容或删除不共用的信息。
- 不得猜测、补全或根据竞品资料推断产品事实。
- 未确认的事实不得写入最终可提交内容。
- 不得逐句复制五点、原样搬用 Listing 副图，或在多个模块中重复相同图片和相同信息。

## 6. 模块专属规则

### 热点模块

- 热点必须落在商品真实部件或功能区域上。
- 热点标题和说明必须与所指部件一一对应。
- 不得虚构内部结构、材料或工作原理。

### 静态轮播模块

- 每个面板的商品颜色、结构、配件和比例必须一致。
- 场景、动作和功能状态必须真实、合理且安全。
- 面板数量及字段长度不得超过后台限制。

### 技术规格表

- 每行只能对应一个参数。
- 数值、单位、范围和定义必须准确一致。
- 可调范围必须同时写明最小值和最大值。
- 不得把包装尺寸写成商品尺寸。
- 不得使用无适用边界的 `fits everyone`、`universal` 等表达。

### 同品牌对比表

- 只能比较同一品牌旗下的真实商品。
- 每列必须对应正确的 ASIN 和图片。
- 所有商品必须使用相同的属性、单位和定义。
- 不得手工写入价格、星级、评论数或购买引导。
- 不得虚构商品、功能或差异，不得为突出当前商品而故意遗漏其他型号已有功能。

### Premium Q&A

- 问题和答案必须基于真实、可验证的商品信息，并与全部应用 ASIN 一致。
- 不得包含价格、促销、物流、保修、退换货或客服信息。
- 不得伪装顾客评价或编造事实。

### 双图与四图模块

- 每张图片必须与其标题和说明一一对应。
- 不得用翻转图片、替换背景或近似场景重复同一内容。
- 四图模块中的四项必须属于同一信息层级，每项只表达一个事实。

## 7. 提交前硬性检查

- 模块数量、字段长度、图片格式、文件大小、尺寸和移动端要求符合当前后台限制。
- 每张图片均有准确 Alt Text。
- 所有内容与当前 ASIN 及其他 Listing 字段一致。
- 所有参数、认证、测试、奖项和效果声称均有证据且适用范围准确。
- 不含本规则列出的任何禁止内容。
