# SKU可用关键词库工作簿合同

## 1. 输入锁

运行前锁定：

- 源工作簿绝对路径、文件名、大小、SHA-256和修改时间；
- Run_ID与输出目录；
- `最终关键词决策总表`的表头行、使用范围和唯一`Keyword_ID`人口；
- `SKU事实卡`的唯一目标SKU/ASIN和事实行；
- `最终去向=品类相关`候选人口；
- 本Skill版本或内容哈希。

源文件只读，输出使用新文件名。不得覆盖、原地保存或清理源文件。

## 2. 必需输入字段

`最终关键词决策总表`必须至少包含：

- `Keyword_ID`
- `英文关键词`
- `中文翻译`
- `最终去向`
- `月搜索量`
- `ABA月排名`
- `流量层`

同时必须存在唯一命名的`品类产品通用词库`、`词频统计`、`关键词竞争性分析`和`关键词趋势性分析`四张Sheet。允许读取`中心购买对象、品类关系、通用词库资格、保留理由`和动态语义列辅助理解，但不得改写或当作SKU事实证据。

## 3. 关键词分类映射

第一列`关键词分类`唯一来源是`最终关键词决策总表.流量层`，使用以下封闭映射：

| 源值 | 输出值 |
|---|---|
| `F1` | `核心大词` |
| `F2` | `二级词` |
| `F3` | `中流量词` |
| `F4` | `中长尾词` |
| `F5` | `长尾词` |

不得使用`长尾主分组标签`、动态语义标签或模型判断替代该映射，不在输出值中附加F编码，不根据ABA重新计算F层。除下述合法缺失组合外，空流量层、未定义层或状态/数值/层矛盾均停止受影响输出并回报主任务。

### 3.1 合法ABA缺失的窄兼容（AKW-LISTING-INTERFACE-v1）

上游允许`分类状态`精确等于`关键词ABA排名缺失`、ABA确实不可用、`流量层`空白。只有三者同时成立且有当前候选Keyword_ID对应的原始来源证据，才将最终`关键词分类`留空。该候选继续原SKU事实、字符及拼写门，不因缺失本身筛除，不虚构F6、二级词或其他标签。

- 规范缺失为Excel空单元格/JSON null；空字符串仅接受为读取层空值，不接受空格、N/A、横线、Excel错误或任意文本标记。
- 若原ABA数值确为0，只有原始来源明确证明这是源0且ABA不可用时才保留原0并兼容；不得用0替代空白。负数、非有限值、布尔及异常数值回上游核实。
- 分类状态为单一精确字符串，不切分、修剪或猜测复合文本。ABA有效时才允许正常空状态、`搜索量缺失`或`没有搜索量`并机械映射F1–F5；本模块不重算阈值或搜索量。
- ABA有效而层空、ABA缺失但层非空、缺失状态配有效ABA等都属于不兼容，不能借例外放行。
- `分类状态`对既有合法F1–F5行可缺列；需要使用空分类例外时必须能读取精确状态及证据。并存搜索量缺失留在原字段和源缺失清单中，不因单一状态而丢弃。
- 账本额外保留原ABA、原分类状态、原流量层、Keyword_ID、源文件/哈希/单元格及原缺失原因；最终五列不增加过程状态列。

可用纯函数[分类兼容检查](../scripts/classification_compat.py)及其[边界测试](../scripts/test_classification_compat.py)检查读入值组合。调用者必须先真正读取并核验原始证据指针、文件哈希、Keyword_ID和源单元格/记录，再传入`verified_evidence`；不能自填true放行。函数只检查传入记录的结构与一致性，不读取原工作簿，也不证明证据真实性、替代SKU判断或发出READY。来源未核验时不得传入“已核验”记录。

## 4. 过程决策账本

账本覆盖全部候选，每个`Keyword_ID`恰好一行，至少记录：

- `Keyword_ID`
- `源工作簿行号`
- `英文关键词`
- `SKU事实匹配`
- `SKU事实匹配依据`
- `SKU最终结论`
- `字符规则结果`
- `拼写规则结果`
- `拼写规则依据`
- `Sheet1输出资格`
- `判定规则版本`

账本属于过程证据，不进入最终用户工作簿。它可以是JSONL、CSV或独立过程Sheet，但必须保留文本和稳定主键，不得只保留汇总计数。

`SKU最终结论`只能由`SKU事实匹配`单维度机械映射：`通过→SKU可用、不通过→SKU不可用、待确认→待确认`。不得新增或沿用搜索意图判断字段影响结论。

`字符规则结果`允许值只有`通过、字符规则排除`。由于第一张Sheet直接作为Listing关键词来源，原始`英文关键词`只有完整匹配`^[A-Za-z]+(?: [A-Za-z]+)*$`才通过：

- 允许字符只有ASCII`A–Z/a–z`；单词之间只允许一个ASCII空格。
- 任意数字、非ASCII字母、标点或符号均标记`字符规则排除`。这包括但不限于中英文引号/撗号、连字符、加减号、中英文逗号、句点、斜杠、反斜杠、冒号、分号、括号、下划线、星号、与号、井号、百分号、货币符号、emoji、对象替换符等。
- 首尾空格、连续空格、Tab、换行或其他控制字符均标记`字符规则排除`。
- 不得通过删除符号、合并空格、转写字符、改写拼写或使用`标准化关键词`规避排除。

`拼写规则结果`允许值只有`通过、拼写规则排除、拼写待确认`。判断主文本仍为原始`英文关键词`：

- 完整短语语境能唯一指向正确词，且出现多字母、少字母、错字母或字母顺序错位时，标记`拼写规则排除`，例如`gamming chair→gaming chair`、`gaming chait→gaming chair`。
- 仅因单复数、常规词形、非英语词、品牌/型号、行业缩写、地区拼法或通用词典未收录，不得判为错拼。
- 品牌词只能与SKU事实卡锁定的品牌拼写比较；不得使用模型常识猜品牌。
- 错拼明显但正确词不能唯一确定时，标记`拼写待确认`；不得纠错后写入Sheet1。
- `拼写规则依据`必须记录原错词以及唯一可确定的正确词，或说明待确认原因。

`Sheet1输出资格`只有在`SKU最终结论=SKU可用`、`字符规则结果=通过`且`拼写规则结果=通过`时为`纳入`，其他情况均为`不纳入`并保留原因。

## 5. SKU可用关键词库五字段映射

第一张Sheet名为`SKU可用关键词库`，只写`Sheet1输出资格=纳入`的行。

| 最终字段 | 来源与生成规则 |
|---|---|
| `关键词分类` | 按第3节机械映射F1–F5；仅满足3.1的合法ABA缺失例外留空，不能自补分类。 |
| `关键词` | 原表`英文关键词`原值。不得改用`标准化关键词`，不得纠错、词干化、改单复数、合并同义词或重排词序。 |
| `中文翻译` | 原表`中文翻译`原值。不得重新翻译覆盖；发现明显冲突写入问题记录。 |
| `月搜索量` | 原表同名字段，保留数值类型和空值。 |
| `ABA月排名` | 原表同名字段，保留数值类型和空值。 |

最终列顺序必须与上表一致。不输出`竞争性强度、Keyword_ID`、来源、流量层、长尾主分组标签、LT分组、匹配结论、依据、广告或Listing字段。

## 6. 四张继承Sheet原样复制

从同一锁定输入复制以下四张Sheet，并保持名称和顺序：

1. `品类产品通用词库`
2. `词频统计`
3. `关键词竞争性分析`
4. `关键词趋势性分析`

“原样复制”表示不执行重新分析、筛选、重排、重命名、删列、改值、改公式或样式重建。优先以锁定原工作簿作为输出底稿，在OOXML工作簿包中直接保留四张目标Sheet及其从属关系部件，只删除无关Sheet并插入新的第一张Sheet。复制后必须保持源Sheet的：

- 单元格值、数据类型、公式和公式结果；
- 合并单元格、行高、列宽、隐藏状态、冻结窗格、筛选和打印/视图设置；
- 字体、填充、边框、对齐、数字格式和条件格式；
- 表格、图表、图片、形状及其引用关系。

`品类产品通用词库`不等于上游独立`二类词`Sheet，也不等于F2`二级词`；本合同仍只继承上述四表，不追加独立二类词或扩大候选人口。额外交付须另行明确。

执行前必须扫描四张目标Sheet的跨Sheet公式与图表数据引用。若依赖将被删除的其他Sheet，则停止并报告；不得静态化公式或图表。若目标Sheet自包含，则可以进行包级保留，但必须验证目标Sheet XML、从属drawing/chart关系部件及媒体部件与锁定输入一致。工作簿目录和关系文件因删除/新增Sheet产生的必要变化不要求位级一致。

若所用方法不能忠实保存某种源对象，或复制后出现公式/图表引用断裂，不得用截图、静态值或重建图表冒充原样复制；应停止并报告具体对象与影响范围。

## 7. 排序与重复

- 默认保持`最终关键词决策总表`源行顺序，不按月搜索量、ABA或竞争性重新排序。
- 以`Keyword_ID`作为审计主键，不按标准化词或翻译合并不同主键。
- 若同一`Keyword_ID`重复或映射到多个源行，停止。
- 不同`Keyword_ID`具有相同英文关键词时不得静默去重；写入问题记录并保持主键级判断，最终是否合并需主任务明确规则。

## 8. 输出和质量检查

最终输出为一个新`.xlsx`：

- 恰好五张可见Sheet，顺序为`SKU可用关键词库、品类产品通用词库、词频统计、关键词竞争性分析、关键词趋势性分析`；
- 第一张Sheet恰好五列，字段名和顺序精确一致；
- 数据行数等于过程账本中`Sheet1输出资格=纳入`数量；
- 每行五个值均可回查到同一源`Keyword_ID`；
- 第一张Sheet的`关键词`列每个值均完整匹配`^[A-Za-z]+(?: [A-Za-z]+)*$`；数字、非ASCII字母、标点、符号、控制字符和异常空白零混入，字符规则排除人口可由过程账本复算；
- 月搜索量和ABA保持数值或空值，不转成描述文本；
- 第一张Sheet长文本可读、表头可筛选、首行冻结，匹配源工作簿的基础视觉语言；
- 四张复制Sheet的使用范围、单元格值、公式、关键样式、合并、行列尺寸、冻结、筛选、图表/绘图对象数量及引用关系与源Sheet一致；目标Sheet及其从属绘图/图表/媒体部件通过包级哈希或规范化XML比较；
- 无新增公式错误、断裂外部链接、宏、隐藏Sheet或多余字段；
- 完成五张Sheet的渲染和目视复核。

## 9. 完成状态

- `completed`：所有候选已判断，零系统性规则缺口，最终工作簿与账本通过质量门。
- `completed_with_pending_rows`：只存在逐行`待确认`，这些行未进入最终工作簿且清单完整。
- `incomplete`：必需字段、事实、哈希、人口或检查缺失。
- `blocked`：已确认主键漂移、源文件被改、系统性规则冲突或输出质量门失败。
