# Amazon 标题与 Item Highlights 硬性规则

> 适用范围：Amazon 美国站及采用同版规则的欧洲站非媒体类目  
> Books、DVDs 等媒体类目及存在单独规则的站点/类目，以当前 Seller Central 及类目规则为准。

## 1. 字段边界

- Item name/商品标题与 Item Highlights/商品亮点是两个独立字段。
- Item Highlights 不是 Bullet Points/Key Product Features/五点描述，不得替代五点。

## 2. Item name 硬性规则

### 字符数

- 非媒体类目最多 75 个字符。
- 空格和标点计入字符数。
- 75 个字符合规，超过 75 个字符不合规。

### 重复词

- 同一个词在标题中最多出现 2 次。
- 介词、冠词和连词不受该重复次数限制。
- 大小写变化不构成不同单词。

### 受限字符

- 标题中禁止使用 `!`、`$`、`?`、`_`、`{`、`}`、`^`、`¬`、`¦`。
- 受限字符属于正式品牌名称组成部分时，才可随品牌名称使用。

### 禁止内容

- 价格、优惠券、折扣比例、促销、交易、库存紧迫性、配送承诺或保证性表达。
- 竞争对手品牌、竞争对手 ASIN、外部网址、联系方式或站外引流。
- 无法证明的排名、最高级、比较级或绝对化表述。
- 未经确认或与当前商品不一致的材质、尺寸、数量、颜色、功能、兼容性、认证、性能或适用人群。

### 项目呈现边界（v2.2用户修订）

- Title与Item Highlights均不包含颜色词；事实卡颜色仍保留。
- Title不用set、combo及同类无信息量的泛套装填充词；此条不影响06词库及其他字段真实说明附件。
- 两字段不要求自然语言完整句；在各自75/125上限内尽量用足必要信息，不凑无意义字符。

### 真实性与变体一致性

- 标题中的全部信息必须真实、准确、可验证并与当前商品一致。
- 标题不呈现颜色；其余采用的尺寸、数量等属性必须与当前子体一致。

## 3. Item Highlights 硬性规则

### 字符数

- 最多 125 个字符。
- 空格和标点计入字符数。
- 125 个字符合规，超过 125 个字符不合规。

### 格式

- 允许按确认卖点优先级用逗号/分号分隔短语、配置和参数，不强制自然语言句子；必要使用/适配信息须纳入取舍。
- 不得写成长句、第二条长标题、关键词堆砌串或五点描述。

### 与标题去重

- 按用户最新修订IH-TITLE-DEDUPE-01：标题已表达的卖点不在IH重复，包含T0；尚未表达的T0与重要卖点按确认顺序补入。
- 按卖点含义去重，不通过同义词或规格改写规避；不同的未表达参数可以补充。此条不等于禁止全部共有品类词根，也不限制Bullet深入解释已有卖点。
- 不得将旧标题从第 76 个字符处机械切开后直接放入 Item Highlights。

### 禁止内容与真实性

- 全部信息必须真实、准确、可验证并与当前商品一致。
- 不得虚构材质、尺寸、功能、用途、认证、性能或比较优势。
- 不得加入价格、折扣、促销、配送、保证、排名、最高级、绝对化或无法证明的比较性表达。
- 不得加入竞争对手品牌、竞争对手 ASIN、外部网址、联系方式或站外引流。

## 4. 跨字段一致性

- Item name、Item Highlights、Bullet Points、商品属性、图片、描述及 A+ 中的商品事实必须一致。
- 不得通过字段拆分规避字符、重复词、受限字符、真实性或禁止内容要求。

## 5. 提交前硬性检查

- Item name 不超过 75 个字符，Item Highlights 不超过 125 个字符。
- 标题重复词次数及受限字符合规。
- IH只补标题未表达的卖点及必要信息；标题已覆盖T0不强制再写。允许短语罗列，两字段均无颜色词。
- 两个字段均不含促销、交易、配送、保证、竞品、站外信息或无法证明的表述。
- 所有信息与当前子 ASIN 及其他 Listing 字段一致。
