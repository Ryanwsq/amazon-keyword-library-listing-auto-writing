# 五 Sheet 最终工作簿固定格式

本参考只规定 SOP V2 标签优先级工作簿的结构、排序和视觉呈现。业务阈值和判断规则以 `tag-priority-sop-v2.md` 为准。

## 全局要求

- 仅含五个固定 Sheet，不增加封面、说明或隐藏计算 Sheet。
- 每张表第 1 行为筛选表头；隐藏默认网格线；正文使用 Microsoft YaHei 10 pt；表头使用深海军蓝 `#16324F`、白色粗体。
- ASIN 按文本保存；计数使用 `#,##0`；Coverage 使用 `0.0%`；Market Expression 使用 `0.00`。
- 长文本自动换行；标识、状态和数值居中，证据、理由和产品事实左对齐。
- 使用正式 Excel Table 与筛选按钮；冻结表头，并在宽表中冻结关键识别列。
- 不用颜色装饰随机行。颜色只表达状态、标签类型、ASIN 分区或内容优先级。

## 固定颜色语义

标签类型：

| 类型 | 浅色分区 | 强调色 |
|---|---|---|
| 人群 | `#E8F1FB` | `#2F75B5` |
| 场景 | `#EAF4EA` | `#548235` |
| 用途 | `#FFF1E3` | `#C55A11` |
| 频率 | `#F1EAF7` | `#8064A2` |

ASIN 状态：有效 `#EFF8F0`，部分执行 `#FFF7E6`，身份异常 `#FDECEC`，无效 `#F2F2F2`。

内容优先级：优先级 1 `#E2F0D9`，优先级 2 `#DDEBF7`，优先级 3 `#FFF2CC`，不采用/观察 `#F2F2F2`。优先级列使用对应深色底与白色粗体。

## Sheet 1｜竞品打标签

- 固定 13 列，列名和顺序严格按 SOP。
- 行顺序：有效 → 部分执行 → 身份异常 → 无效；同一状态内按 ASIN 排序。
- 整行使用状态浅色；状态切换处使用中等粗细上边框。
- 有效 ASIN 集中位于顶部，ASIN 使用粗体深蓝字。

## Sheet 2｜标签覆盖率

- 固定 9 列，列名和顺序严格按 SOP。
- 先按标签类型排序：人群 → 场景 → 用途 → 频率；类型内按覆盖竞品数降序，再按标签字母顺序。
- 类型区间使用对应浅色；类型列使用对应强调色、白色粗体；类型切换处增加中等粗细上边框。
- Coverage 和等级必须由公式计算，覆盖 ASIN 保持可追溯。

## Sheet 3｜标签介绍度

- 固定 15 列，粒度为 ASIN × 覆盖标签。
- 先按有效 ASIN 顺序分组；每个 ASIN 内按人群、场景、用途、频率排序，再按 Expression Score 降序。
- 相邻 ASIN 组使用 `#F7FAFC` 与 `#EEF4F8` 交替浅色；ASIN 切换处使用蓝色中等粗细上边框。
- 标签类型列按四类颜色强调；命中列与 Expression Score 居中，Expression Score 使用粗体。
- 原始证据摘要和 Amazon URL 保持可见，不用省略号替代底层单元格内容。

## Sheet 4｜标签分类

- 固定 13 列，标签顺序与“标签覆盖率”完全一致。
- 使用与 Sheet 2 相同的类型分区颜色和边界。
- Coverage、Market Expression、市场介绍等级和 A/B1/B2/C 分类必须由公式驱动。
- 分类理由必须显示 Coverage、Market Expression 与归类结果；数据状态显示正式数据、介绍度未验证或样本不足。

## Sheet 5｜产品参数对比与优先级

- 固定 20 列，列名和顺序严格按 SOP。
- 行顺序：优先级 1 → 优先级 2 → 优先级 3 → 不采用/观察；同级内按标签类型、Coverage 降序、Market Expression 降序和标签字母顺序。
- 整行按优先级浅色分区；优先级切换处使用对应强调色的中等粗细上边框。
- 标签类型列使用四类强调色；内容优先级列使用强色底、白色粗体。
- 市场分类、Coverage、Market Expression 必须按标签主键引用“标签分类”，不得假设两张表行号一致。
- “最终人群 / 最终场景 / 最终用途 / 最终频率”只能有一个对应列填写当前标签，其余三个留空。

## 黄金样例的使用

`assets/golden-tag-priority-workbook.xlsx` 是经验证的版式样例，其中业务数据仅用于展示分区效果。

- 生成新任务时先检查其五 Sheet、表头、列宽、配色、分区和筛选结构。
- 新工作簿必须使用当前任务输入重新计算全部数据、公式、证据和结论。
- 禁止把样例中的 ASIN、标签、分数、产品事实或 57D 结论复制到新任务。
